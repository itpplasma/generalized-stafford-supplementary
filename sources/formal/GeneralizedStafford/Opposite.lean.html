Left statements from right statements

For a ring A with an anti-automorphism τ:A≃+∗Aop, the map I↦y∣τ−1(opy)∈I is a bijection from left ideals of A to right ideals of A, and a left A-module is a right A-module through τ. Hence a statement about right ideals and right modules of A yields the same statement for left ideals and left modules, with no extra hypothesis on A.

The results here are generic: they take the right-hand statement as a hypothesis. The two-generator transfer is used for the Weyl algebra in GeneralizedStafford.Weyl.

10# Left statements from right statements

13`I ↦ {y | τ⁻¹(op y) ∈ I}` is a bijection from left ideals of `A` to right ideals
14of `A`, and a left `A`-module is a right `A`-module through `τ`. Hence a
15statement about right ideals and right modules of `A` yields the same statement
16for left ideals and left modules, with no extra hypothesis on `A`.

The right ideal τ(I) attached to a left ideal I by the anti-automorphism τ: y∈τ(I) iff τ−1(opy)∈I.

33/-- The right ideal `τ(I)` attached to a left ideal `I` by the anti-automorphism
34`τ`: `y ∈ τ(I)` iff `τ⁻¹(op y) ∈ I`. -/
35def leftToRight (τ : A ≃+* Aᵐᵒᵖ) (I : Submodule A A) : Submodule Aᵐᵒᵖ A where
36 carrier := {y | τ.symm (op y) ∈ I}
37 add_mem' {x y} hx hy := by
38 change τ.symm (op (x + y)) ∈ I
39 rw [op_add, map_add]
40 exact I.add_mem hx hy
41 zero_mem' := by
42 change τ.symm (op 0) ∈ I
43 simp
44 smul_mem' r y hy := by
45 change τ.symm (op (y * r.unop)) ∈ I
46 rw [op_mul, map_mul]
47 exact I.smul_mem _ hy

49/-- A left ideal with two generators, from the two-generator statement for right
50ideals. -/
51theorem twoGeneratedLeft_of_right (τ : A ≃+* Aᵐᵒᵖ)
52 (hR : ∀ J : Submodule Aᵐᵒᵖ A, ∃ a b : A, J = Submodule.span Aᵐᵒᵖ {a, b})
53 (I : Submodule A A) : ∃ a b : A, I = Submodule.span A {a, b} := by
54 obtain ⟨a, b, hab⟩ := hR (leftToRight τ I)
55 refine ⟨τ.symm (op a), τ.symm (op b), ?_⟩
56 ext x
57 have hx : x ∈ I ↔ unop (τ x) ∈ leftToRight τ I := by
58 change x ∈ I ↔ τ.symm (op (unop (τ x))) ∈ I
59 simp
60 rw [hx, hab, Submodule.mem_span_pair, Submodule.mem_span_pair]
61 constructor
62 · rintro ⟨r, s, hrs⟩
63 refine ⟨τ.symm r, τ.symm s, ?_⟩
64 apply τ.injective
65 apply unop_injective
66 simp only [smul_eq_mul, map_add, map_mul, RingEquiv.apply_symm_apply, unop_add,
67 unop_mul, unop_op, ← hrs, MulOpposite.smul_eq_mul_unop]
68 · rintro ⟨r, s, hrs⟩
69 refine ⟨τ r, τ s, ?_⟩
70 rw [← hrs]
71 simp only [smul_eq_mul, map_add, map_mul, RingEquiv.apply_symm_apply, unop_add,
72 unop_mul, unop_op, MulOpposite.smul_eq_mul_unop]

74theorem mem_leftToRight (τ : A ≃+* Aᵐᵒᵖ) (I : Submodule A A) (x : A) :
75 unop (τ x) ∈ leftToRight τ I ↔ x ∈ I := by
76 change τ.symm (op (unop (τ x))) ∈ I ↔ x ∈ I

The transfer of a left span is the right span of the transferred generators.

86/-- The transfer of a left span is the right span of the transferred generators. -/
87theorem leftToRight_span (τ : A ≃+* Aᵐᵒᵖ) (S : Set A) :
88 leftToRight τ (Submodule.span A S) =
89 Submodule.span Aᵐᵒᵖ ((fun x => unop (τ x)) '' S) := by
90 apply le_antisymm
91 · intro y hy
92 have hy' : τ.symm (op y) ∈ Submodule.span A S := hy
93 have key : ∀ z ∈ Submodule.span A S,
94 unop (τ z) ∈ Submodule.span Aᵐᵒᵖ ((fun x => unop (τ x)) '' S) := by
95 intro z hz
96 induction hz using Submodule.span_induction with
97 | mem z hz => exact Submodule.subset_span ⟨z, hz, rfl⟩
98 | zero => simp
99 | add z w _ _ hz hw => simpa using Submodule.add_mem _ hz hw
100 | smul r z _ hz =>
101 have := Submodule.smul_mem _ (τ r) hz
102 simpa [smul_eq_mul, MulOpposite.smul_eq_mul_unop] using this
103 simpa using key _ hy'
104 · rw [Submodule.span_le]
105 rintro _ ⟨z, hz, rfl⟩
106 exact (mem_leftToRight τ _ z).2 (Submodule.subset_span hz)

108/-- Prescribed first generator for left ideals, from the right statement. -/
109theorem prescribedTwoGeneratedLeft_of_right (τ : A ≃+* Aᵐᵒᵖ)
110 (hR : ∀ (J : Submodule Aᵐᵒᵖ A) (a : A), a ∈ J → a ≠ 0 → ∀ y ∈ J, ∀ t : A, t ≠ 0 →
111 ∃ h ∈ J, J = Submodule.span Aᵐᵒᵖ {a} ⊔ Submodule.span Aᵐᵒᵖ {y + h * t})
112 (I : Submodule A A) (a : A) (haI : a ∈ I) (ha : a ≠ 0) (y : A) (hy : y ∈ I)
113 (t : A) (ht : t ≠ 0) :
114 ∃ h ∈ I, I = Submodule.span A {a} ⊔ Submodule.span A {y + t * h} := by
115 have hne : ∀ z : A, z ≠ 0 → unop (τ z) ≠ 0 := fun z hz h0 =>
116 hz (τ.injective (by simpa using congrArg op h0))
117 obtain ⟨h', hh', hJ⟩ := hR (leftToRight τ I) (unop (τ a))
118 ((mem_leftToRight τ I a).2 haI) (hne a ha) (unop (τ y))
119 ((mem_leftToRight τ I y).2 hy) (unop (τ t)) (hne t ht)

A left A-module viewed as a right module through τ: m * r := τ⁻¹(op r) • m. This is a local definition, not an instance.

131/-- A left `A`-module viewed as a right module through `τ`:

133abbrev rightOfLeft (τ : A ≃+* Aᵐᵒᵖ) : Module Aᵐᵒᵖ M :=
134 Module.compHom M (τ.symm : Aᵐᵒᵖ →+* A)

The right span of S in rightOfLeft τ is the left span of S.

136/-- The right span of `S` in `rightOfLeft τ` is the left span of `S`. -/
137theorem span_rightOfLeft (τ : A ≃+* Aᵐᵒᵖ) (S : Set M) :
138 ((@Submodule.span Aᵐᵒᵖ M _ _ (rightOfLeft τ) S : Set M)) = Submodule.span A S := by
139 let := rightOfLeft (M := M) τ
140 apply le_antisymm
141 · let N : Submodule Aᵐᵒᵖ M :=
142 { carrier := Submodule.span A S
143 add_mem' := fun hx hy => Submodule.add_mem _ hx hy
144 zero_mem' := Submodule.zero_mem _
145 smul_mem' := fun r m hm => Submodule.smul_mem _ (τ.symm r) hm }
146 exact (Submodule.span_le (p := N)).2 Submodule.subset_span
147 · let N : Submodule A M :=
148 { carrier := Submodule.span Aᵐᵒᵖ S
149 add_mem' := fun hx hy => Submodule.add_mem _ hx hy
150 zero_mem' := Submodule.zero_mem _
151 smul_mem' := fun r m hm => by
152 have := Submodule.smul_mem _ (τ r) hm
153 change τ.symm (τ r) • m ∈ _ at this
154 simpa using this }
155 exact (Submodule.span_le (p := N)).2 Submodule.subset_span

Prescribed cyclic generator for left modules, from the right statement.

157/-- Prescribed cyclic generator for left modules, from the right statement. -/
158theorem prescribedCyclicLeft_of_right (τ : A ≃+* Aᵐᵒᵖ)
159 (hR : ∀ (M : Type v) [AddCommGroup M] [Module Aᵐᵒᵖ M] [Module.Finite Aᵐᵒᵖ M],
160 (∀ m : M, ∃ d : A, d ≠ 0 ∧ op d • m = 0) →
161 ∀ (x : M) (t : A), t ≠ 0 → ∃ h : M, Submodule.span Aᵐᵒᵖ {x + op t • h} = ⊤)
162 [Module.Finite A M] (hM : ∀ m : M, ∃ d : A, d ≠ 0 ∧ d • m = 0)
163 (x : M) (t : A) (ht : t ≠ 0) :
164 ∃ h : M, Submodule.span A {x + t • h} = ⊤ := by
165 let := rightOfLeft (M := M) τ
166 have hsmul : ∀ (r : Aᵐᵒᵖ) (m : M), r • m = τ.symm r • m := fun _ _ => rfl
167 have htop : ∀ S : Set M, Submodule.span Aᵐᵒᵖ S = ⊤ ↔ Submodule.span A S = ⊤ := by
168 intro S
169 rw [← SetLike.coe_set_eq, ← SetLike.coe_set_eq (q := (⊤ : Submodule A M)),
170 span_rightOfLeft]
171 rfl
172 have : Module.Finite Aᵐᵒᵖ M := by
173 obtain ⟨S, hS⟩ := (Module.finite_def.mp ‹Module.Finite A M›)
174 exact Module.finite_def.mpr ⟨S, (htop _).2 hS⟩
175 have hne : ∀ z : A, z ≠ 0 → unop (τ z) ≠ 0 := fun z hz h0 =>
176 hz (τ.injective (by simpa using congrArg op h0))
177 obtain ⟨h, hh⟩ := hR M (fun m => by
178 obtain ⟨d, hd, hdm⟩ := hM m
179 exact ⟨unop (τ d), hne d hd, by simpa [hsmul] using hdm⟩)
180 x (unop (τ t)) (hne t ht)
181 refine ⟨h, (htop _).1 ?_⟩
182 simpa [hsmul] using hh
