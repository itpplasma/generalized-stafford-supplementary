Corollary B: rings of deviation at most ω

Statement. If R is right Noetherian with KdimR≤ω, then δ(d)=Kdim(R/dR) is finite for every regular d, and Kdim(R/I) is finite for every right ideal I containing a regular element; hence Theorems A and A' hold for all such d and I under (S), (N), (Z).

Proof idea. Left multiplication by a regular d is an injective endomorphism of RR​ with image dR. In the descending chain R⊇dR⊇d2R⊇⋯ every factor is isomorphic to R/dR, so by the definition of KdimR≤ω the factor R/dR has finite deviation (Module.DevLEOmega.quotient_range_of_injective). A right ideal containing a regular s contains sR, so R/I is a quotient of R/sR.

Principal quotients. If KdimR≤ω, then R/dR has finite deviation for every regular d.

31/-- **Principal quotients.** If `Kdim R ≤ ω`, then `R/dR` has
32finite deviation for every regular `d`. -/
33theorem principal_quotient_finite_of_omega (homega : Module.DevLEOmega Rᵐᵒᵖ R)
34 {d : R} (hd : d ∈ R⁰) : ∃ N, Module.DevLE Rᵐᵒᵖ N (R ⧸ principalRightIdeal d) :=
35 homega.quotient_range_of_injective (leftMulLinear d) fun x y hxy => by
36 have h : d * (x - y) = 0 := by
37 rw [mul_sub]
38 exact sub_eq_zero.mpr hxy
39 exact sub_eq_zero.mp (hd.1 _ h)

Right ideals. If KdimR≤ω, then R/I has finite deviation for every right ideal I containing a regular element.

46/-- **Right ideals.** If `Kdim R ≤ ω`, then `R/I` has finite deviation for
47every right ideal `I` containing a regular element. -/
48theorem quotient_finite_of_omega (homega : Module.DevLEOmega Rᵐᵒᵖ R)
49 {I : Submodule Rᵐᵒᵖ R} (hreg : ∃ s ∈ I, s ∈ R⁰) :
50 ∃ N, Module.DevLE Rᵐᵒᵖ N (R ⧸ I) := by
51 obtain ⟨s, hsI, hs⟩ := hreg
52 obtain ⟨N, hN⟩ := principal_quotient_finite_of_omega homega hs
53 exact ⟨N, devLE_quotient_of_le hN (principalRightIdeal_le hsI)⟩

59/-- **Corollary B for Theorem A'.** If `Kdim R ≤ ω` and `I` contains a regular
60element, then for every `x` and `t ≠ 0` there is `H` with
61`I + (x + H t)R = R`. -/
62theorem fixed_ideal_of_devLE_omega (homega : Module.DevLEOmega Rᵐᵒᵖ R)
63 {I : Submodule Rᵐᵒᵖ R} (hreg : ∃ s ∈ I, s ∈ R⁰) (x : R) {t : R} (ht : t ≠ 0) :
64 ∃ H : R, I ⊔ principalRightIdeal (x + H * t) = ⊤ := by
65 obtain ⟨N, hfin⟩ := quotient_finite_of_omega homega hreg
66 exact fixed_ideal (k := k) hreg hfin x ht

69/-- **Corollary B for Theorem A.** If `Kdim R ≤ ω`, then for every regular `d`,

72 {d : R} (hd : d ∈ R⁰) {a : R} (ha : a ≠ 0) (B : R) :
