The two-call descent

Fix a right ideal I containing a regular element s. With N=Kdim(R/I), the assertion P(h) is IdealBound I e for e=N−h+1: for all x, all t=0 and every finite family of tests there is f=x+Ht satisfying the tests with KdimR/(I+fR)<e. (The strict stratum Kdim<e is Module.Small Rᵐᵒᵖ e, so Kdim≤N−h is Small(N−h+1).)

  • **Base P(0)** (idealBound_initial): source selection (GermTest.exists_affine_satisfied).
  • **Step P(h)→P(h+1)** (idealBound_step): the eight steps proved in idealBound_step. The first call gives f=x+Ht and J=I+fR; a regular b with fb∈I exists by Goldie's theorem; the second call, for the same I, with offset 0, tail tb and the single unit test of R/J, gives gb with Q=I+gbR; then qQ​f is epic, a good nonzero central λ keeps qQ​(f+λg) epic and all old tests satisfied, the inclusion (4.2) gives Q⊆I+(f+λg)R, so the dimension drops, and f+λg=x+(H+λH2​)t.
  • Termination (idealBound_zero): N+1 steps reach P(N+1), i.e. KdimR/(I+fR)<0.

8# The two-call descent
9
10Fix a right ideal `I` containing a regular element `s`. With `N = Kdim(R/I)`,
11the assertion `P(h)` is `IdealBound I e` for `e = N - h + 1`: for
12all `x`, all `t ≠ 0` and every finite family of tests there is `f = x + H t`
13satisfying the tests with `Kdim R/(I + fR) < e`. (The strict stratum
14`Kdim < e` is `Module.Small Rᵐᵒᵖ e`, so `Kdim ≤ N - h` is `Small (N - h + 1)`.)
15
16* **Base `P(0)`** (`idealBound_initial`): source selection (`GermTest.exists_affine_satisfied`).
17* **Step `P(h) → P(h+1)`** (`idealBound_step`): the eight steps proved in `idealBound_step`.
18 The first call gives `f = x + H t` and `J = I + fR`; a regular `b` with
19 `f b ∈ I` exists by Goldie's theorem; the second call, for the same `I`, with
20 offset `0`, tail `t b` and the single unit test of `R/J`, gives `g b` with
21 `Q = I + g b R`; then `q_Q f` is epic, a good nonzero central `λ` keeps
22 `q_Q (f + λ g)` epic and all old tests satisfied, the inclusion (4.2) gives
23 `Q ⊆ I + (f + λ g)R`, so the dimension drops, and
24 `f + λ g = x + (H + λ H₂) t`.
25* **Termination** (`idealBound_zero`): `N + 1` steps reach `P(N+1)`,
26 i.e. `Kdim R/(I + fR) < 0`.
27-/

The induction assertion P(h), with e=N−h+1: for all x, all t=0 and every finite family of tests there is H such that f=x+Ht satisfies the tests and KdimR/(I+fR)<e.

38/-- The induction assertion `P(h)`, with `e = N - h + 1`: for all
39`x`, all `t ≠ 0` and every finite family of tests there is `H` such that
40`f = x + H t` satisfies the tests and `Kdim R/(I + fR) < e`. -/
41def IdealBound (I : Submodule Rᵐᵒᵖ R) (e : ℕ) : Prop :=
42 ∀ (x t : R), t ≠ 0 → ∀ {ι : Type u} [Fintype ι] (tests : ι → GermTest R),
43 ∃ H : R, Module.Small Rᵐᵒᵖ e (R ⧸ (I ⊔ principalRightIdeal (x + H * t))) ∧
44 ∀ i, (tests i).Satisfied (x + H * t)

The pencil inclusion. If fb∈I and λ is a central unit, then gb∈I+(f+λg)R, since gbλ=(f+λg)b−fb.

46/-- **The pencil inclusion.** If `f b ∈ I` and `λ` is a central unit, then
47`g b ∈ I + (f + λ g)R`, since `g b λ = (f + λ g) b - f b`. -/
48theorem mul_mem_sup_pencil {I : Submodule Rᵐᵒᵖ R} {f g b lam : R}
49 (hfb : f * b ∈ I) (hlam : ∀ x : R, lam * x = x * lam) (hu : IsUnit lam) :
50 g * b ∈ I ⊔ principalRightIdeal (f + lam * g) := by
51 obtain ⟨u, rfl⟩ := hu
52 have h1 : (f + ↑u * g) * b ∈ I ⊔ principalRightIdeal (f + ↑u * g) :=
53 Submodule.mem_sup_right ⟨b, rfl⟩
54 have h2 : g * b * ↑u = (f + ↑u * g) * b - f * b := by
55 rw [add_mul, mul_assoc (↑u : R) g b, hlam (g * b)]; abel
56 have h3 : g * b * ↑u ∈ I ⊔ principalRightIdeal (f + ↑u * g) := by
57 rw [h2]; exact Submodule.sub_mem _ h1 (Submodule.mem_sup_left hfb)
58 have h4 := Submodule.smul_mem _ (op (↑u⁻¹ : R)) h3
59 have h5 : op (↑u⁻¹ : R) • (g * b * ↑u) = g * b := by
60 change g * b * ↑u * ↑u⁻¹ = g * b
61 rw [mul_assoc, Units.mul_inv, mul_one]
62 rwa [h5] at h4

67 (x + H * t) + lam * (H₂ * t) = x + (H + lam * H₂) * t := by

**The two-call step P(h)→P(h+1)** for a right ideal I containing a regular element s: IdealBound I (e + 1) implies IdealBound I e.

The proof follows Steps 1--8, marked by comments in the proof. It makes no case split on whether KdimR/J<e (where f already proves P(h+1)) or KdimR/J=e. The unit test (e,VJ​,qJ​,0,1) (unitTest) is formed at level e whenever KdimR/J≤e, and steps 2--8 then go through uniformly; in the first case the top Fe​(R/J) is zero and the unit test is vacuous.

The two hypotheses enter as follows. Infinite centre enters in Steps 5--7 only: step 5 needs a nonzero central λ outside a finite exceptional set, which exists because k is infinite; steps 6 and 7 use that λ is a central unit (mul_mem_sup_pencil, test_pencil_identity). Finite deviation is not used here; it enters only in the termination idealBound_zero, where KdimR/I≤N bounds the number of steps.

85/-- **The two-call step `P(h) → P(h+1)`** for a right ideal `I` containing a
86regular element `s`: `IdealBound I (e + 1)` implies `IdealBound I e`.
87
88The proof follows Steps 1--8, marked by comments in the proof. It makes no
89case split on whether `Kdim R/J < e` (where `f` already proves `P(h+1)`) or
90`Kdim R/J = e`. The unit test
91`(e, V_J, q_J, 0, 1)` (`unitTest`) is formed at level `e` whenever
92`Kdim R/J ≤ e`, and steps 2--8 then go through uniformly; in the first case
93the top `F_e(R/J)` is zero and the unit test is vacuous.
94
95The two hypotheses enter as follows. **Infinite centre**
96enters in Steps 5--7 only: step 5 needs a nonzero central `λ` outside a finite
97exceptional set, which exists because `k` is infinite; steps 6 and 7 use that
98`λ` is a central unit (`mul_mem_sup_pencil`, `test_pencil_identity`). **Finite deviation** is not used here; it enters only in the termination
99`idealBound_zero`, where `Kdim R/I ≤ N` bounds the number of steps. -/
100theorem idealBound_step {I : Submodule Rᵐᵒᵖ R} {s : R} (hsI : s ∈ I) (hs : s ∈ R⁰)
101 (e : ℕ) (hbound : IdealBound I (e + 1)) : IdealBound I e := by
102 classical
103 intro x t ht ι _ tests
104 -- Step 1 (first call): `f = x + H t` satisfies the tests, `Kdim R/J ≤ e`.
105 obtain ⟨H, hJ, htests⟩ := hbound x t ht tests
106 set f := x + H * t with hf
107 set J := I ⊔ principalRightIdeal f with hJdef
108 -- Step 2 (torsion equation): a regular `b` with `f b ∈ I` (Goldie's theorem).
109 obtain ⟨b, hb, hfb⟩ := exists_mul_mem_of_mem_nonZeroDivisors hsI hs f
110 have htb : t * b ≠ 0 := fun h0 => ht (hb.2 t h0)
111 -- Step 3 (second call, same `I`): offset `0`, tail `t b`, the unit test of `R/J`.
112 obtain ⟨H₂, hQ, htest⟩ := hbound 0 (t * b) htb
113 (fun _ : PUnit.{u + 1} => unitTest J e hJ
114 (isGoldieTorsion_quotient (Submodule.mem_sup_left hsI) hs))
115 set g := H₂ * t with hg
116 have hgb : (0 : R) + H₂ * (t * b) = g * b := by rw [zero_add, hg, mul_assoc]
117 have htJ := (unitTest_satisfied_iff _ _ _ _ _).mp (htest PUnit.unit)
118 rw [hgb] at hQ htJ
119 set Q := I ⊔ principalRightIdeal (g * b) with hQdef
120 -- Step 4 (vanishing of the joint top): `J + g b R = Q + f R`, so `v = q_Q f` is epic.
121 have hjoint : J ⊔ principalRightIdeal (g * b) = Q ⊔ principalRightIdeal f := by
122 rw [hJdef, hQdef, sup_assoc, sup_assoc, sup_comm (principalRightIdeal f)]
123 rw [hjoint] at htJ
124 have hv : Hom.Epic (op f • Hom.ofLinearMap (e := e) Q.mkQ) :=
125 (smul_mkQ_epic_iff Q f).mpr htJ
126 -- Step 5 (good central scalar): `λ ≠ 0` outside the finitely many exceptions.
127 let F := Classical.choice hQ.nonempty_criticalFiltration
128 have hbad := germ_pencil_finite (k := k) hQ F
129 (op f • Hom.ofLinearMap (e := e) Q.mkQ) (op g • Hom.ofLinearMap (e := e) Q.mkQ) hv
130 have hold : (⋃ i, {c : k | ¬ (tests i).Satisfied (f + algebraMap k R c * g)}).Finite :=
131 Set.finite_iUnion fun i => (tests i).pencil_finite (htests i) g
132 obtain ⟨c, hc⟩ := ((hbad.union hold).union (Set.finite_singleton (0 : k))).exists_notMem
133 have hc0 : c ≠ 0 := fun h => hc (Set.mem_union_right _ h)
134 set lam := algebraMap k R c with hlamdef
135 have hlam : ∀ y : R, lam * y = y * lam := fun y => Algebra.commutes c y
136 have hunit : IsUnit lam := (IsUnit.mk0 c hc0).map (algebraMap k R)
137 have hep : Hom.Epic (op f • Hom.ofLinearMap (e := e) Q.mkQ +
138 op lam • (op g • Hom.ofLinearMap (e := e) Q.mkQ)) := by
139 by_contra hn
140 exact hc (Set.mem_union_left _ (Set.mem_union_left _ hn))
141 have hkeep : ∀ i, (tests i).Satisfied (f + lam * g) := by
142 intro i
143 by_contra hn
144 exact hc (Set.mem_union_left _ (Set.mem_union_right _ (Set.mem_iUnion.mpr ⟨i, hn⟩)))
145 -- Step 6 (pencil inclusion): `Q ⊆ J' = I + (f + λ g)R`.
146 have hideal : Q ⊔ principalRightIdeal (f + lam * g) =
147 I ⊔ principalRightIdeal (f + lam * g) := by
148 apply le_antisymm
149 · refine sup_le (sup_le le_sup_left ?_) le_sup_right
150 rintro y ⟨r, rfl⟩
151 exact Submodule.smul_mem _ (op r) (mul_mem_sup_pencil hfb hlam hunit)
152 · exact sup_le (le_sup_left.trans le_sup_left) le_sup_right
153 -- Step 7 (drop): `q_Q (f + λ g) = v + u λ` is epic, so `Kdim R/J' < e`.
154 have hep' : Hom.Epic (op (f + lam * g) • Hom.ofLinearMap (e := e) Q.mkQ) := by
155 have hid := test_pencil_identity (Hom.ofLinearMap (e := e) Q.mkQ) 0 f g 1 lam hlam
156 simp only [mul_one, zero_add] at hid
157 rwa [hid]
158 have hsmall := (smul_mkQ_epic_iff Q (f + lam * g)).mp hep'
159 rw [hideal] at hsmall
160 -- Step 8 (affine form): `f + λ g = x + (H + λ H₂) t`.
161 have heq : f + lam * g = x + (H + lam * H₂) * t := affine_update x H H₂ t lam
162 rw [heq] at hsmall hkeep
163 exact ⟨H + lam * H₂, hsmall, hkeep⟩

Termination. If I contains a regular element and KdimR/I≤N, then IdealBound I 0: the N+1 steps from P(0) reach P(N+1).

166/-- **Termination.** If `I` contains a regular element and
167`Kdim R/I ≤ N`, then `IdealBound I 0`: the `N + 1` steps from `P(0)` reach
168`P(N+1)`. -/
169theorem idealBound_zero {I : Submodule Rᵐᵒᵖ R} (hreg : ∃ s ∈ I, s ∈ R⁰)
170 {N : ℕ} (hfin : Module.DevLE Rᵐᵒᵖ N (R ⧸ I)) : IdealBound I 0 := by
171 obtain ⟨s, hsI, hs⟩ := hreg
172 have descend : ∀ h, IdealBound I h → IdealBound I 0 := fun h => by
173 induction h with
174 | zero => exact id
175 | succ h ih => exact fun hb => ih (idealBound_step (k := k) hsI hs h hb)
176 exact descend (N + 1) (idealBound_initial (k := k) hfin)
