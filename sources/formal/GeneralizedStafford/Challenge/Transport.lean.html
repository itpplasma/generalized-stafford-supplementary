Challenge transport: the challenge definitions and their proofs

The definitions and statement definitions of GeneralizedStaffordChallenge.lean (identical copy Challenge.lean) are restated verbatim below, in the same namespace and under the same names, so that the solution never imports the challenge. The compared theorems of the challenge are not restated: each challenge theorem <name> is proved here as <name>proof​, and GeneralizedStaffordSolution.lean restates it under its challenge name.

The bridge lemmas translate the challenge conventions into those of the library: Submodule.span Rᵐᵒᵖ {d} is principalRightIdeal d (span_singleton_eq), IsRegularElement d is d∈R0 (isRegular_iff), the deviation bounds are AlgebraicAnalysis' Module.DevLE and Module.DevLEOmega (devDimLE_iff, hOmega_iff), (H_all) is PrincipalQuotientsFinite (hAll_iff), the infinite centre becomes an infinite central field (withCentre).

An element d of R is regular if it is a two-sided non-zero-divisor: dx=0 implies x=0, and xd=0 implies x=0 . This is definitionally Mathlib's d∈R0.

45/-- An element `d` of `R` is **regular** if it is a two-sided non-zero-divisor:
46`d x = 0` implies `x = 0`, and `x d = 0` implies `x = 0` .
47This is definitionally Mathlib's `d ∈ R⁰`. -/
48def IsRegularElement {R : Type u} [Ring R] (d : R) : Prop :=
49 (∀ x : R, d * x = 0 → x = 0) ∧ (∀ x : R, x * d = 0 → x = 0)

Finite Gabriel--Rentschler deviation of a partial order. PosetDevLE 0 α says that every descending chain in α stabilizes; PosetDevLE (n + 1) α says that for every descending chain c0​≥c1​≥⋯ all but finitely many closed intervals [ci+1​,ci​] satisfy PosetDevLE n, i.e. all but finitely many factors have deviation <n+1 .

51/-- Finite Gabriel--Rentschler deviation of a partial order. `PosetDevLE 0 α`
52says that every descending chain in `α` stabilizes; `PosetDevLE (n + 1) α`
53says that for every descending chain `c₀ ≥ c₁ ≥ ⋯` all but finitely many
54closed intervals `[cᵢ₊₁, cᵢ]` satisfy `PosetDevLE n`, i.e. all but finitely
55many factors have deviation `< n + 1` . -/
56def PosetDevLE : (n : ℕ) → (α : Type v) → [PartialOrder α] → Prop
57 | 0, α, _ => ∀ c : ℕ → α, Antitone c → ∃ N, ∀ i, N ≤ i → c i = c N
58 | n + 1, α, _ => ∀ c : ℕ → α, Antitone c →
59 ∃ N, ∀ i, N ≤ i → PosetDevLE n (Set.Icc (c (i + 1)) (c i))

DevDimLE R M n: KdimM≤n (written Kdim; Gabriel--Rentschler deviation, not classical Krull dimension). The right module M has right deviation dimension at most n , defined on the lattice of right submodules of M.

63/-- `DevDimLE R M n`: `Kdim M ≤ n` (written `Kdim`;
64Gabriel--Rentschler deviation, not classical Krull dimension). The right
65module `M` has right deviation dimension at most `n` , defined
66on the lattice of right submodules of `M`. -/
67def DevDimLE (n : ℕ) : Prop :=
68 PosetDevLE n (Submodule Rᵐᵒᵖ M)
69
70

KdimM is a finite integer (possibly −1, which happens exactly when M=0).

70/-- `Kdim M` is a finite integer (possibly `-1`, which happens exactly when
71`M = 0`). -/
72def HasFiniteDevDim : Prop :=
73 ∃ n : ℕ, DevDimLE R M n
74
75

DevDimLEOmega R M: KdimM≤ω, that is, for every descending chain of right submodules M0​≥M1​≥⋯ all but finitely many factors Mi​/Mi+1​ (the intervals [Mᵢ₊₁, Mᵢ]) have finite deviation.

75/-- `DevDimLEOmega R M`: `Kdim M ≤ ω`, that is, for every descending chain of
76right submodules `M₀ ≥ M₁ ≥ ⋯` all but finitely many factors `Mᵢ/Mᵢ₊₁`
77(the intervals `[Mᵢ₊₁, Mᵢ]`) have finite deviation. -/
78def DevDimLEOmega : Prop :=
79 ∀ c : ℕ → Submodule Rᵐᵒᵖ M, Antitone c → ∃ N, ∀ i, N ≤ i →
80 ∃ n : ℕ, PosetDevLE n (Set.Icc (c (i + 1)) (c i))

82

M is Goldie-torsion: every m∈M satisfies ms=0 for some regular s∈R.

82/-- `M` is **Goldie-torsion**: every `m ∈ M` satisfies
83`m s = 0` for some regular `s ∈ R`. -/
84def IsGoldieTorsion : Prop :=
85 ∀ m : M, ∃ s : R, IsRegularElement s ∧ op s • m = 0

Hypothesis (H_all): δ(d)=Kdim(R/dR) is a finite integer for every regular d.

87/-- Hypothesis (H_all): `δ(d) = Kdim(R/dR)` is a finite integer for every
88regular `d`. -/
89def HAll : Prop :=
90 ∀ d : R, IsRegularElement d → HasFiniteDevDim R (R ⧸ Submodule.span Rᵐᵒᵖ {d})

Hypothesis (H_omega): KdimR≤ω for the right regular module RR​.

92/-- Hypothesis (H_omega): `Kdim R ≤ ω` for the right regular module `R_R`. -/
93def HOmega : Prop :=
94 DevDimLEOmega R R

Theorem A' (fixed ideal). Let R be a simple (S), right Noetherian (N) ring with infinite centre (Z). Let I be a right ideal containing a regular element such that Kdim(R/I) is a finite integer. Then for every x∈R and every nonzero t∈R there is H∈R with I+(x+Ht)R=R.

100/-- **Theorem A' (fixed ideal).** Let `R` be a simple (S), right Noetherian (N)
101ring with infinite centre (Z). Let `I` be a right ideal containing a regular
102element such that `Kdim(R/I)` is a finite integer. Then for
103every `x ∈ R` and every nonzero `t ∈ R` there is `H ∈ R` with
104`I + (x + H t)R = R`. -/
105def FixedIdealStatement : Prop :=
106 ∀ (R : Type u) [Ring R] [IsSimpleRing R] [IsNoetherian Rᵐᵒᵖ R]
107 [Infinite (Subring.center R)] (I : Submodule Rᵐᵒᵖ R),
108 (∃ s ∈ I, IsRegularElement s) → HasFiniteDevDim R (R ⧸ I) →
109 ∀ x t : R, t ≠ 0 →
110 ∃ H : R, I ⊔ Submodule.span Rᵐᵒᵖ {x + H * t} = ⊤

Theorem A (fixed anchor). Let R satisfy (S), (N), (Z) and let d be a regular element with δ(d)=Kdim(R/dR) a finite integer. For every nonzero a∈R (possibly a zero-divisor) and every B∈R there are H,U,V∈R with 1=dU+(B+Ha)dV.

112/-- **Theorem A (fixed anchor).** Let `R` satisfy (S), (N), (Z) and let `d` be a
113regular element with `δ(d) = Kdim(R/dR)` a finite integer. For every nonzero
114`a ∈ R` (possibly a zero-divisor) and every `B ∈ R` there are `H, U, V ∈ R`
115with `1 = d U + (B + H a) d V`. -/
116def FixedAnchorStatement : Prop :=
117 ∀ (R : Type u) [Ring R] [IsSimpleRing R] [IsNoetherian Rᵐᵒᵖ R]
118 [Infinite (Subring.center R)] (d : R),
119 IsRegularElement d → HasFiniteDevDim R (R ⧸ Submodule.span Rᵐᵒᵖ {d}) →
120 ∀ a B : R, a ≠ 0 →
121 ∃ H U V : R, 1 = d * U + (B + H * a) * d * V
