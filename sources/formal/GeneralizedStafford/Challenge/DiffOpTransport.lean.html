Challenge transport: differential operators on a smooth affine variety

The definitions of the differential-operator section of GeneralizedStaffordChallenge.lean (identical copy Challenge.lean) and the GlobalStaffordChallenge definitions of the Global Stafford statement are restated verbatim below, in the same namespaces and under the same names, so that the solution never imports the challenge. Each compared theorem <name> is proved here as <name>proof​; GeneralizedStaffordSolution.lean restates it under its challenge name.

The bridge: IsDifferentialOperator P is membership of P in AlgebraicAnalysis' subalgebra DifferentialOperators.algebra of finite-order operators (isDifferentialOperator_iff, by induction on the order), and diffOpskA equals that subalgebra (diffOps_eq_algebra). The ring-level statements of GeneralizedStafford.DiffOp are transported along this equality by substitution, and the element-level statements by the membership equivalence.

The commutator [P, a] = P ∘ a - a ∘ P of an endomorphism with a multiplication operator.

IsOrderLE n P says that P is a differential operator of order at most n: order 0 operators commute with every multiplication, and P has order at most n+1 when every commutator [P, a] has order at most n.

39/-- `IsOrderLE n P` says that `P` is a differential operator of order at most
40`n`: order `0` operators commute with every multiplication, and `P` has order
41at most `n + 1` when every commutator `[P, a]` has order at most `n`. -/
42def IsOrderLE : ℕ → Module.End k A → Prop
43 | 0, P => ∀ a : A, commutator P a = 0
44 | n + 1, P => ∀ a : A, IsOrderLE n (commutator P a)

Differential operators on a smooth affine variety

Let k be a field of characteristic zero and A a smooth domain of finite type over k. Let Dk​(A) be the ring of k-linear finite-order differential operators on A, as defined by GlobalStaffordChallenge.IsDifferentialOperator. Products are compositions. The closure proofs of diffOps below are complete and elementary ([PQ, a] = P [Q, a] + [P, a] Q); they are not compared theorems. The statements that need only elements (Theorem A, the Global Stafford identity) are written in Module.End k A with explicit IsDifferentialOperator side conditions.

70theorem endCommutator_zero (a : A) :
71 GlobalStaffordChallenge.commutator (0 : Module.End k A) a = 0 := by

74theorem endCommutator_add (P Q : Module.End k A) (a : A) :
75 GlobalStaffordChallenge.commutator (P + Q) a =
76 GlobalStaffordChallenge.commutator P a + GlobalStaffordChallenge.commutator Q a := by
77 simp only [GlobalStaffordChallenge.commutator, add_mul, mul_add, add_sub_add_comm]
78theorem endCommutator_mul (P Q : Module.End k A) (a : A) :
79 GlobalStaffordChallenge.commutator (P * Q) a =
80 P * GlobalStaffordChallenge.commutator Q a + GlobalStaffordChallenge.commutator P a * Q := by
81 simp only [GlobalStaffordChallenge.commutator, mul_sub, sub_mul, mul_assoc, sub_add_sub_cancel]
82theorem isOrderLE_zero : ∀ n, IsOrderLE n (0 : Module.End k A) := by
83 intro n
84 induction n with
85 | zero => exact fun a => endCommutator_zero a
86 | succ n ih => exact fun a => by rw [endCommutator_zero]; exact ih
87theorem isOrderLE_add : ∀ {n} {P Q : Module.End k A},
88 IsOrderLE n P → IsOrderLE n Q → IsOrderLE n (P + Q) := by
89 intro n
90 induction n with
91 | zero => exact fun hP hQ a => by rw [endCommutator_add, hP a, hQ a, add_zero]
92 | succ n ih => exact fun hP hQ a => by rw [endCommutator_add]; exact ih (hP a) (hQ a)
93theorem isOrderLE_succ : ∀ {n} {P : Module.End k A}, IsOrderLE n P → IsOrderLE (n + 1) P := by
94 intro n
95 induction n with
96 | zero => exact fun hP a => by rw [hP a]; exact isOrderLE_zero 0
97 | succ n ih => exact fun hP a => ih (hP a)
98theorem isOrderLE_mono {m n : ℕ} {P : Module.End k A} (h : m ≤ n) (hP : IsOrderLE m P) :
99 IsOrderLE n P := by
100 induction n, h using Nat.le_induction with
101 | base => exact hP
102 | succ n _ ih => exact isOrderLE_succ ih

Orders add under composition.

104/-- Orders add under composition. -/
105theorem isOrderLE_mul : ∀ (N : ℕ) {m n : ℕ} {P Q : Module.End k A}, m + n = N →
106 IsOrderLE m P → IsOrderLE n Q → IsOrderLE N (P * Q) := by
107 intro N
108 induction N with
109 | zero =>
110 intro m n P Q h hP hQ a
111 obtain ⟨rfl, rfl⟩ := Nat.add_eq_zero_iff.mp h
112 rw [endCommutator_mul, hP a, hQ a, mul_zero, zero_mul, add_zero]
113 | succ N ih =>
114 intro m n P Q h hP hQ a
115 rw [endCommutator_mul]
116 refine isOrderLE_add ?_ ?_
117 · cases n with
118 | zero => rw [hQ a, mul_zero]; exact isOrderLE_zero N
119 | succ n => exact ih (Nat.add_right_cancel ((Nat.add_assoc m n 1).trans h)) hP (hQ a)
120 · cases m with
121 | zero => rw [hP a, zero_mul]; exact isOrderLE_zero N
122 | succ m => exact ih (Nat.add_right_cancel ((Nat.add_right_comm m 1 n).symm.trans h)) (hP a) hQ

The k-subalgebra Dk​(A) of Module.End k A: the finite-order differential operators, with composition as product.

125/-- The `k`-subalgebra `D_k(A)` of `Module.End k A`: the finite-order differential operators,
126with composition as product. -/
127def diffOps (k A : Type u) [CommRing k] [CommRing A] [Algebra k A] :
128 Subalgebra k (Module.End k A) where
129 carrier := {P | IsDifferentialOperator P}
130 add_mem' := fun ⟨m, hP⟩ ⟨n, hQ⟩ =>
131 ⟨max m n, isOrderLE_add (isOrderLE_mono (le_max_left m n) hP)
132 (isOrderLE_mono (le_max_right m n) hQ)⟩
133 mul_mem' := fun ⟨m, hP⟩ ⟨n, hQ⟩ => ⟨m + n, isOrderLE_mul _ rfl hP hQ⟩
134 algebraMap_mem' c := ⟨0, fun _ => sub_eq_zero.mpr (Algebra.commutes c _)⟩

Two generators for right ideals of Dk​(A). For a field k of characteristic zero and a smooth domain A of finite type over k, every right ideal I of Dk​(A) is generated by two elements: I=aDk​(A)+bDk​(A).

143smooth domain `A` of finite type over `k`, every right ideal `I` of `D_k(A)` is generated by two

Theorem A for Dk​(A). With k and A as above, for all differential operators d,a,B with d=0 and a=0 there are differential operators H,U,V with 1=dU+(B+Ha)dV (right form), and differential operators H,U,V with 1=Ud+Vd(B+aH) (left form). Products are compositions.

159/-- Theorem A for `D_k(A)`. With `k` and `A` as above, for all differential operators `d, a, B`
160with `d ≠ 0` and `a ≠ 0` there are differential operators `H, U, V` with
161`1 = d U + (B + H a) d V` (right form), and differential operators `H, U, V` with
162`1 = U d + V d (B + a H)` (left form). Products are compositions. -/
163def DiffOpFixedAnchorStatement : Prop :=
164 ∀ (k : Type u) [Field k] [CharZero k]
165 (A : Type u) [CommRing A] [IsDomain A] [Algebra k A] [Algebra.Smooth k A]
166 (d a B : Module.End k A),
167 IsDifferentialOperator d → IsDifferentialOperator a → IsDifferentialOperator B →
168 d ≠ 0 → a ≠ 0 →
169 (∃ H U V : Module.End k A,
170 IsDifferentialOperator H ∧ IsDifferentialOperator U ∧ IsDifferentialOperator V ∧
171 (1 : Module.End k A) = d * U + (B + H * a) * d * V) ∧
172 (∃ H U V : Module.End k A,
173 IsDifferentialOperator H ∧ IsDifferentialOperator U ∧ IsDifferentialOperator V ∧
174 (1 : Module.End k A) = U * d + V * d * (B + a * H))

The Global Stafford identity for Dk​(A). With k and A as above, for every nonzero differential operator d there are differential operators F,R,S with 1=dR+FdS, the products being compositions.

176/-- The Global Stafford identity for `D_k(A)`. With `k` and `A` as above, for every nonzero
177differential operator `d` there are differential operators `F, R, S` with `1 = d R + F d S`,
178the products being compositions. -/
179def DiffOpGlobalStaffordStatement : Prop :=
180 ∀ (k : Type u) [Field k] [CharZero k]
181 (A : Type u) [CommRing A] [IsDomain A] [Algebra k A] [Algebra.Smooth k A]
182 (d : Module.End k A),
183 IsDifferentialOperator d → d ≠ 0 →
184 ∃ F R S : Module.End k A,
185 IsDifferentialOperator F ∧ IsDifferentialOperator R ∧
186 IsDifferentialOperator S ∧
187 (1 : Module.End k A) = d * R + F * d * S

189/-- Cyclicity of torsion right `D_k(A)`-modules. With `k` and `A` as above, let `M` be a finitely
190generated right `D_k(A)`-module in which every element is killed by a nonzero operator. For every
191`x ∈ M` and every nonzero `t ∈ D_k(A)` there is `h ∈ M` with `M = (x + h t) D_k(A)`; in
192particular `M` is cyclic. -/
193def DiffOpCyclicRightStatement : Prop :=
194 ∀ (k : Type u) [Field k] [CharZero k]
195 (A : Type u) [CommRing A] [IsDomain A] [Algebra k A] [Algebra.Smooth k A]
196 (M : Type v) [AddCommGroup M] [Module (diffOps k A)ᵐᵒᵖ M]
197 [Module.Finite (diffOps k A)ᵐᵒᵖ M],
198 (∀ m : M, ∃ s : diffOps k A, s ≠ 0 ∧ op s • m = 0) →
199 ∀ (x : M) (t : diffOps k A), t ≠ 0 →
200 ∃ h : M, Submodule.span (diffOps k A)ᵐᵒᵖ {x + op t • h} = ⊤
