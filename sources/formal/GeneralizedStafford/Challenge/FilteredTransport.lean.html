The conclusion of Theorem A for every regular anchor (Corollary B): for every regular d, every nonzero a and every B there are H,U,V with 1=dU+(B+Ha)dV.

37/-- The conclusion of Theorem A for every regular anchor (Corollary B): for
38every regular `d`, every nonzero `a` and every `B` there are `H, U, V` with
39`1 = d U + (B + H a) d V`. -/
40def FixedAnchorProperty : Prop :=
41 ∀ d a B : R, IsRegularElement d → a ≠ 0 →
42 ∃ H U V : R, 1 = d * U + (B + H * a) * d * V

The conclusion of Theorem A' for every right ideal containing a regular element (Corollary B): I+(x+Ht)R=R for some H, for every x and every nonzero t.

44/-- The conclusion of Theorem A' for every right ideal containing a regular
45element (Corollary B): `I + (x + H t)R = R` for some `H`, for every `x` and
46every nonzero `t`. -/
47def FixedIdealProperty : Prop :=
48 ∀ I : Submodule Rᵐᵒᵖ R, (∃ s ∈ I, IsRegularElement s) →
49 ∀ x t : R, t ≠ 0 → ∃ H : R, I ⊔ Submodule.span Rᵐᵒᵖ {x + H * t} = ⊤

(C.1), prescribed generator: every finitely generated Goldie-torsion right module M satisfies M=(x+ht)R for some h, for every x∈M and every nonzero t∈R.

51/-- (C.1), prescribed generator: every finitely generated Goldie-torsion right
52module `M` satisfies `M = (x + h t)R` for some `h`, for every `x ∈ M` and every
53nonzero `t ∈ R`. -/
54def PrescribedCyclicProperty : Prop :=
55 ∀ (M : Type v) [AddCommGroup M] [Module Rᵐᵒᵖ M] [Module.Finite Rᵐᵒᵖ M],
56 IsGoldieTorsion R M →
57 ∀ (x : M) (t : R), t ≠ 0 → ∃ h : M, Submodule.span Rᵐᵒᵖ {x + op t • h} = ⊤

59

(C.1), stable cyclicity: for Goldie-torsion elements c,u of a right module and every nonzero t there is H with cR+uR=(c+uHt)R.

59/-- (C.1), stable cyclicity: for Goldie-torsion elements `c, u` of a right
60module and every nonzero `t` there is `H` with `cR + uR = (c + u H t)R`. -/
61def StablyCyclicProperty : Prop :=
62 ∀ (M : Type v) [AddCommGroup M] [Module Rᵐᵒᵖ M] (c u : M),
63 (∃ s : R, IsRegularElement s ∧ op s • c = 0) →
64 (∃ s : R, IsRegularElement s ∧ op s • u = 0) →
65 ∀ t : R, t ≠ 0 →
66 ∃ H : R, Submodule.span Rᵐᵒᵖ {c, u} = Submodule.span Rᵐᵒᵖ {c + op (H * t) • u}
67
68

(C.2): every right ideal I is aR+(y+ht)R for every a∈I with aQ=IQ (every y′∈I has a regular s with y′s∈aR), every y∈I and every nonzero t, with some h∈I; and every right ideal is generated by two elements.

68/-- (C.2): every right ideal `I` is `aR + (y + h t)R` for every `a ∈ I` with
69`aQ = IQ` (every `y' ∈ I` has a regular `s` with `y' s ∈ aR`), every `y ∈ I`
70and every nonzero `t`, with some `h ∈ I`; and every right ideal is generated
71by two elements. -/
72def TwoGeneratedProperty : Prop :=
73 (∀ (I : Submodule Rᵐᵒᵖ R) (a : R), a ∈ I →
74 (∀ y ∈ I, ∃ s : R, IsRegularElement s ∧ y * s ∈ Submodule.span Rᵐᵒᵖ {a}) →
75 ∀ y ∈ I, ∀ t : R, t ≠ 0 →
76 ∃ h ∈ I, I = Submodule.span Rᵐᵒᵖ {a} ⊔ Submodule.span Rᵐᵒᵖ {y + h * t}) ∧
77 ∀ I : Submodule Rᵐᵒᵖ R, ∃ a b : R, I = Submodule.span Rᵐᵒᵖ {a, b}

323/-- A nonzero element of a domain is regular. -/

Filtered rings with a domain as associated graded ring: Theorem A for every nonzero anchor, on both sides. The domain structure makes R a domain (AlgebraicAnalysis GradedSymbol.noZeroDivisors), so nonzero elements are regular.

336/-- Filtered rings with a domain as associated graded ring: Theorem A for every
337nonzero anchor, on both sides. The domain structure makes `R` a domain
338(AlgebraicAnalysis `GradedSymbol.noZeroDivisors`), so nonzero elements are regular. -/
339theorem filteredDomain_proof : FilteredDomainStatement.{u} := by
340 intro k _ _ R _ _ _ h
341 obtain ⟨φ, G, cG, aG, 𝒜, gA, ⟨S⟩, hN, hD, hlt⟩ := h
342 obtain ⟨m, hm⟩ := exists_nat_le_of_lt_top hlt
343 have hA : HasCommNoetherianGr k R m := ⟨φ, G, cG, aG, 𝒜, gA, ⟨S⟩, hN, hm⟩
344 obtain ⟨⟨hN1, hZ1, -, hO1⟩, ⟨hN2, hZ2, -, hO2⟩⟩ := filtered_side hA
345 have := hN1
346 have := hZ1
347 have := hN2
348 have := hZ2
349 have : NoZeroDivisors R := (symbolToAA S).noZeroDivisors
350 have hright := fixedAnchorProperty_of_omega hO1
351 have hleft := fixedAnchorProperty_of_omega hO2
352 refine ⟨fun d a B hd ha => hright d a B (isRegular_of_ne_zero' hd) ha, fun d a B hd ha => ?_⟩
353 obtain ⟨H, U, V, hUV⟩ := hleft (op d) (op a) (op B)
354 (isRegular_of_ne_zero' ((op_ne_zero_iff d).mpr hd)) ((op_ne_zero_iff a).mpr ha)
355 refine ⟨unop H, unop U, unop V, ?_⟩
356 have h2 := congrArg MulOpposite.unop hUV
357 simp only [MulOpposite.unop_add, MulOpposite.unop_mul, MulOpposite.unop_op,
358 MulOpposite.unop_one] at h2
359 rw [h2, mul_assoc]
