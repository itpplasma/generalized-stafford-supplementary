Affine generation over simple Noetherian rings with infinite centre

This file states Theorem A', Theorem A and Corollaries B and C (C.1 and C.2), and their applications to the Weyl algebra, filtered rings, simple quotients of enveloping algebras and rings of differential operators. It imports only Mathlib and defines everything else inline.

Conventions

  • Rings are associative and unital; R is nonzero because Mathlib's IsSimpleRing includes nontriviality. Products are read in the displayed order: (B+H∗a)∗d∗V is (B+Ha)dV.
  • Modules are right modules: [Module Rᵐᵒᵖ M], with mr written MulOpposite.op r • m. A right ideal is a Submodule Rᵐᵒᵖ R; Submodule.span Rᵐᵒᵖ {x} is xR (the products x∗r), and R/I is the cyclic right module R/I. Finitely generated means [Module.Finite Rᵐᵒᵖ M].
  • IsRegularElement d is two-sided regularity; it is literally Mathlib's d∈R0 (mem_nonZeroDivisors_iff holds by Iff.rfl), spelled out to make the sidedness visible.
  • DevDimLE R M n is the right Gabriel--Rentschler (deviation) dimension bound KdimM≤n on the lattice of right submodules, the factor Mi​/Mi+1​ being the interval [Mᵢ₊₁, Mᵢ]. It is not the classical Krull dimension of prime chains, nor Mathlib's Order.KrullDimLE, Ring.KrullDimLE, ringKrullDim or Module.length. The zero module satisfies every bound, so "KdimM is a finite integer ≥−1" is HasFiniteDevDim; DevDimLEOmega R M is KdimM≤ω.
  • IsGoldieTorsion R M: every m has ms=0 for some regular s.
  • (S) is IsSimpleRing R (only trivial two-sided ideals); (N) is IsNoetherian Rᵐᵒᵖ R (ACC on right ideals); (Z) is Infinite (Subring.center R). Under (S) the centre is a field (IsSimpleRing.isField_center), so (Z) says that R is an algebra over an infinite central field.

Rings live in universe u, modules in v, for all universes. The compared theorems are the theorems below; each sorry is a deliberate hole, proved in GeneralizedStaffordSolution.lean (identical copy Solution.lean); holes without a proof there are listed in docs/open-holes.md. Left-handed statements are given for the Weyl algebra (the right case transported by the transposition anti-automorphism) and, through Rop, for filtered rings (last section).

An element d of R is regular if it is a two-sided non-zero-divisor: dx=0 implies x=0, and xd=0 implies x=0 . This is definitionally Mathlib's d∈R0.

64/-- An element `d` of `R` is **regular** if it is a two-sided non-zero-divisor: `d x = 0` implies
65`x = 0`, and `x d = 0` implies `x = 0` . This is definitionally Mathlib's `d ∈ R⁰`. -/
66def IsRegularElement {R : Type u} [Ring R] (d : R) : Prop :=
67 (∀ x : R, d * x = 0 → x = 0) ∧ (∀ x : R, x * d = 0 → x = 0)

Finite Gabriel--Rentschler deviation of a partial order. PosetDevLE 0 α says that every descending chain in α stabilizes; PosetDevLE (n + 1) α says that for every descending chain c0​≥c1​≥⋯ all but finitely many closed intervals [ci+1​,ci​] satisfy PosetDevLE n, i.e. all but finitely many factors have deviation <n+1 .

69/-- Finite Gabriel--Rentschler deviation of a partial order. `PosetDevLE 0 α` says that every
70descending chain in `α` stabilizes; `PosetDevLE (n + 1) α` says that for every descending chain
71`c₀ ≥ c₁ ≥ ⋯` all but finitely many closed intervals `[cᵢ₊₁, cᵢ]` satisfy `PosetDevLE n`, i.e. all
72but finitely many factors have deviation `< n + 1` . -/
73def PosetDevLE : (n : ℕ) → (α : Type v) → [PartialOrder α] → Prop
74 | 0, α, _ => ∀ c : ℕ → α, Antitone c → ∃ N, ∀ i, N ≤ i → c i = c N
75 | n + 1, α, _ => ∀ c : ℕ → α, Antitone c →
76 ∃ N, ∀ i, N ≤ i → PosetDevLE n (Set.Icc (c (i + 1)) (c i))

DevDimLE R M n: KdimM≤n (written Kdim; Gabriel--Rentschler deviation, not classical Krull dimension). The right module M has right deviation dimension at most n , defined on the lattice of right submodules of M.

80/-- `DevDimLE R M n`: `Kdim M ≤ n` (written `Kdim`; Gabriel--Rentschler deviation, not classical
81Krull dimension). The right module `M` has right deviation dimension at most `n` , defined on the
82lattice of right submodules of `M`. -/
83def DevDimLE (n : ℕ) : Prop :=

DevDimLEOmega R M: KdimM≤ω, that is, for every descending chain of right submodules M0​≥M1​≥⋯ all but finitely many factors Mi​/Mi+1​ (the intervals [Mᵢ₊₁, Mᵢ]) have finite deviation.

90/-- `DevDimLEOmega R M`: `Kdim M ≤ ω`, that is, for every descending chain of right submodules
91`M₀ ≥ M₁ ≥ ⋯` all but finitely many factors `Mᵢ/Mᵢ₊₁` (the intervals `[Mᵢ₊₁, Mᵢ]`) have finite
92deviation. -/

94 ∀ c : ℕ → Submodule Rᵐᵒᵖ M, Antitone c → ∃ N, ∀ i, N ≤ i →
95 ∃ n : ℕ, PosetDevLE n (Set.Icc (c (i + 1)) (c i))

Theorem A' (fixed ideal). Let R be a simple (S), right Noetherian (N) ring with infinite centre (Z). Let I be a right ideal containing a regular element such that Kdim(R/I) is a finite integer. Then for every x∈R and every nonzero t∈R there is H∈R with I+(x+Ht)R=R.

112/-- **Theorem A' (fixed ideal).** Let `R` be a simple (S), right Noetherian (N) ring with infinite
113centre (Z). Let `I` be a right ideal containing a regular element such that `Kdim(R/I)` is a finite
114integer. Then for every `x ∈ R` and every nonzero `t ∈ R` there is `H ∈ R` with
115`I + (x + H t)R = R`. -/

119 (∃ s ∈ I, IsRegularElement s) → HasFiniteDevDim R (R ⧸ I) →
