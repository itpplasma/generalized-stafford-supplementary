17 # Affine generation over simple Noetherian rings with infinite centre
18 
19 This file states Theorem A', Theorem A and Corollaries B and C (C.1 and C.2),
20 and their applications to the Weyl algebra, filtered rings, simple quotients
21 of enveloping algebras and rings of differential operators.
22 It imports only Mathlib and defines everything else inline.
23 
24 ## Conventions
25 
26 * Rings are associative and unital; `R` is nonzero because Mathlib's
27   `IsSimpleRing` includes nontriviality.
28 * Modules are **right** modules. A right `R`-module `M` is a Mathlib module
29   over the opposite ring, `[Module Rᵐᵒᵖ M]`; the product `m r` is written
30   `MulOpposite.op r • m`. In particular a right ideal of `R` is a
31   `Submodule Rᵐᵒᵖ R`, and `Submodule.span Rᵐᵒᵖ {x}` is the principal right
32   ideal `xR` (its elements are the products `x * r`, in this order). The
33   quotient `R ⧸ I` is the cyclic right module `R/I`.
34 * Products in `R` are read in the displayed order: `(B + H * a) * d * V`
35   is `(B + H a) d V`, never a reordering of it.
36 * `IsRegularElement d` is two-sided regularity: `d x = 0 → x = 0` and
37   `x d = 0 → x = 0`. It is literally Mathlib's membership `d ∈ R⁰`
38   (`mem_nonZeroDivisors_iff` holds by `Iff.rfl`); it is spelled out here so
39   that a reader need not look up the sidedness of `nonZeroDivisors`.
40 * `DevDimLE R M n` is the right **Gabriel--Rentschler (deviation)
41   dimension** bound `Kdim M ≤ n` (written `Kdim`; it is
42   unrelated to Mathlib's `Order.KrullDimLE` and `Ring.KrullDimLE`), defined
43   on the lattice of right submodules: `Kdim ≤ 0` means that every descending chain stabilizes, and
44   `Kdim ≤ n + 1` means that for every descending chain
45   `M₀ ≥ M₁ ≥ ⋯` all but finitely many factors `Mᵢ/Mᵢ₊₁` have `Kdim ≤ n`.
46   The factor `Mᵢ/Mᵢ₊₁` is represented by the interval `[Mᵢ₊₁, Mᵢ]` of the
47   submodule lattice, which is order isomorphic to its submodule lattice.
48   The zero module satisfies every bound, so "`Kdim M` is a finite integer
49   `≥ -1`" is `∃ n : ℕ, DevDimLE R M n` (`HasFiniteDevDim`).
50   This is **not** the classical (Krull) dimension of chains of prime ideals
51   and not Mathlib's `ringKrullDim`/`Module.length`; it is the deviation of
52   the submodule poset. `DevDimLEOmega R M` is `Kdim M ≤ ω`: for every
53   descending chain all but finitely many factors have finite dimension.
54 * `IsGoldieTorsion R M`: every `m` has `m s = 0` for some regular `s`.
55 * (S) is Mathlib's `IsSimpleRing R` (nonzero, only the trivial two-sided
56   ideals). (N) is `IsNoetherian Rᵐᵒᵖ R`: right ideals satisfy the ascending
57   chain condition. (Z) is `Infinite (Subring.center R)`: the centre is
58   infinite. Under (S) the centre is a field (Mathlib's
59   `IsSimpleRing.isField_center`), so (Z) is the same as "`R` is an algebra
60   over an infinite central field".
61 * Finitely generated right modules are `[Module.Finite Rᵐᵒᵖ M]`.
62 
63 Rings live in universe `u` and modules in universe `v`; the theorems are
64 stated for all universes. The compared theorems are the `theorem`s below;
65 each `sorry` is a deliberate hole. The proofs are in
66 `GeneralizedStaffordSolution.lean` (identical copy `Solution.lean`) of this
67 repository; holes without a proof there are listed in `docs/open-holes.md`.
68 
69 Left-handed statements are stated for the Weyl algebra and, through the opposite ring `Rᵐᵒᵖ`, for filtered rings (last section); for the Weyl algebra the left case is the right case transported by the transposition anti-automorphism.

82 variable (R : Type u) [Ring R]

84 /-- An element `d` of `R` is **regular** if it is a two-sided non-zero-divisor:
85 `d x = 0` implies `x = 0`, and `x d = 0` implies `x = 0` .
86 This is definitionally Mathlib's `d ∈ R⁰`. -/
87 def IsRegularElement {R : Type u} [Ring R] (d : R) : Prop :=
88   (∀ x : R, d * x = 0 → x = 0) ∧ (∀ x : R, x * d = 0 → x = 0)
89 
90 /-- Finite Gabriel--Rentschler deviation of a partial order. `PosetDevLE 0 α`
91 says that every descending chain in `α` stabilizes; `PosetDevLE (n + 1) α`
92 says that for every descending chain `c₀ ≥ c₁ ≥ ⋯` all but finitely many
93 closed intervals `[cᵢ₊₁, cᵢ]` satisfy `PosetDevLE n`, i.e. all but finitely
94 many factors have deviation `< n + 1` . -/
95 def PosetDevLE : (n : ℕ) → (α : Type v) → [PartialOrder α] → Prop
96   | 0, α, _ => ∀ c : ℕ → α, Antitone c → ∃ N, ∀ i, N ≤ i → c i = c N
97   | n + 1, α, _ => ∀ c : ℕ → α, Antitone c →
98       ∃ N, ∀ i, N ≤ i → PosetDevLE n (Set.Icc (c (i + 1)) (c i))
99 
100 variable (M : Type v) [AddCommGroup M] [Module Rᵐᵒᵖ M]
101 
102 /-- `DevDimLE R M n`: `Kdim M ≤ n` (written `Kdim`;
103 Gabriel--Rentschler deviation, not classical Krull dimension). The right
104 module `M` has right deviation dimension at most `n` , defined
105 on the lattice of right submodules of `M`. -/
106 def DevDimLE (n : ℕ) : Prop :=
107   PosetDevLE n (Submodule Rᵐᵒᵖ M)
108 
109 /-- `Kdim M` is a finite integer (possibly `-1`, which happens exactly when
110 `M = 0`). -/
111 def HasFiniteDevDim : Prop :=
112   ∃ n : ℕ, DevDimLE R M n
113 
114 /-- `DevDimLEOmega R M`: `Kdim M ≤ ω`, that is, for every descending chain of
115 right submodules `M₀ ≥ M₁ ≥ ⋯` all but finitely many factors `Mᵢ/Mᵢ₊₁`
116 (the intervals `[Mᵢ₊₁, Mᵢ]`) have finite deviation. -/
117 def DevDimLEOmega : Prop :=
118   ∀ c : ℕ → Submodule Rᵐᵒᵖ M, Antitone c → ∃ N, ∀ i, N ≤ i →
119     ∃ n : ℕ, PosetDevLE n (Set.Icc (c (i + 1)) (c i))
120 
121 /-- `M` is **Goldie-torsion**: every `m ∈ M` satisfies
122 `m s = 0` for some regular `s ∈ R`. -/
123 def IsGoldieTorsion : Prop :=
124   ∀ m : M, ∃ s : R, IsRegularElement s ∧ op s • m = 0
125 
126 /-- Hypothesis (H_all): `δ(d) = Kdim(R/dR)` is a finite integer for every
127 regular `d`. -/
128 def HAll : Prop :=
129   ∀ d : R, IsRegularElement d → HasFiniteDevDim R (R ⧸ Submodule.span Rᵐᵒᵖ {d})
130 
131 /-- Hypothesis (H_omega): `Kdim R ≤ ω` for the right regular module `R_R`. -/
132 def HOmega : Prop :=
133   DevDimLEOmega R R
134 
135 end Definitions

139 /-- **Theorem A' (fixed ideal).** Let `R` be a simple (S), right Noetherian (N)
140 ring with infinite centre (Z). Let `I` be a right ideal containing a regular
141 element such that `Kdim(R/I)` is a finite integer. Then for
142 every `x ∈ R` and every nonzero `t ∈ R` there is `H ∈ R` with
143 `I + (x + H t)R = R`. -/
144 def FixedIdealStatement : Prop :=
145   ∀ (R : Type u) [Ring R] [IsSimpleRing R] [IsNoetherian Rᵐᵒᵖ R]
146     [Infinite (Subring.center R)] (I : Submodule Rᵐᵒᵖ R),
147     (∃ s ∈ I, IsRegularElement s) → HasFiniteDevDim R (R ⧸ I) →
148     ∀ x t : R, t ≠ 0 →
149       ∃ H : R, I ⊔ Submodule.span Rᵐᵒᵖ {x + H * t} = ⊤
150

172 /-- **Known input to Corollary B.** Let `R` be right Noetherian with
173 `Kdim R ≤ ω` (H_omega). Then `δ(d) = Kdim(R/dR)` is a finite integer for every
174 regular `d`, that is, (H_all) holds: `R` has Krull dimension

177 because Corollary B uses it. -/

278 /-! ## Corollary C.2
279 
280 The condition `aQ = IQ` (with `Q` the classical right quotient ring)
281 is stated elementwise: `a ∈ I` and every `y ∈ I` has a regular `s` with
282 `y s ∈ aR`. Under (S), (N) these are equivalent: `aQ ⊆ IQ` because `a ∈ I`,
283 and `y ∈ aQ` iff `y = a r s⁻¹` iff `y s = a r` for some `r` and regular `s`. -/
284 
285 /-- **Existence of a full-rank element** (first step of Corollary C.2). Let `R`
286 satisfy (S) and (N). Every right ideal `I` contains an `a` with `aQ = IQ`, that
287 is, every `y ∈ I` has a regular `s` with `y s ∈ aR`. Corollary C.2 is stated
288 under (S), (N), (Z), (H_all); this step needs only (S) and (N) (Goldie's
289 theorem), so the statement here has fewer hypotheses and is still true. -/
290 def CorollaryC2FullRankStatement : Prop :=
291   ∀ (R : Type u) [Ring R] [IsSimpleRing R] [IsNoetherian Rᵐᵒᵖ R]
292     (I : Submodule Rᵐᵒᵖ R),
293     ∃ a ∈ I, ∀ y ∈ I,
294       ∃ s : R, IsRegularElement s ∧ y * s ∈ Submodule.span Rᵐᵒᵖ {a}
295 
296 /-- **Corollary C.2, prescribed form.** Let `R` satisfy (S), (N), (Z) and
297 (H_all), and let `I` be a right ideal. If `a ∈ I` satisfies `aQ = IQ` (every
298 `y ∈ I` has a regular `s` with `y s ∈ aR`), then for every `y ∈ I` and every
299 nonzero `t ∈ R` there is `h ∈ I` with `I = aR + (y + h t)R`. -/
300 def CorollaryC2PrescribedStatement : Prop :=
301   ∀ (R : Type u) [Ring R] [IsSimpleRing R] [IsNoetherian Rᵐᵒᵖ R]
302     [Infinite (Subring.center R)], HAll R →
303     ∀ (I : Submodule Rᵐᵒᵖ R) (a : R), a ∈ I →
304     (∀ y ∈ I, ∃ s : R, IsRegularElement s ∧ y * s ∈ Submodule.span Rᵐᵒᵖ {a}) →
305     ∀ y ∈ I, ∀ t : R, t ≠ 0 →
306       ∃ h ∈ I, I = Submodule.span Rᵐᵒᵖ {a} ⊔ Submodule.span Rᵐᵒᵖ {y + h * t}

345 challenge. The definitions `Stafford.freeWeylRelation`, `Stafford.FreeWeyl`,
346 `Stafford38Challenge.PhaseVar`, `Stafford38Challenge.WeylAlg`,

352 relations `ι i ι j − ι j ι i = J i j` with `Matrix.J = [[0, −1], [1, 0]]` give
353 `[∂_i, x_j] = δ_ij`, all other generators commuting. -/

361     (a b : FreeAlgebra k ι) : Prop :=

364       FreeAlgebra.ι k j * FreeAlgebra.ι k i ∧

586 /-! ## Filtered rings
587 
588 The hypothesis "`gr R` is commutative Noetherian of finite Krull dimension" is
589 stated through an identification of `gr R = ⨁ₙ Fₙ/Fₙ₋₁` with a commutative
590 graded `k`-algebra `G = ⨁ₙ 𝒜ₙ` (`GradedAlgebra 𝒜`): surjective `k`-linear
591 symbol maps `grₙ : Fₙ → 𝒜ₙ` with kernel `Fₙ₋₁` (`F₋₁ = 0`) that multiply,
592 `gr_{i+j}(x y) = grᵢ(x) grⱼ(y)`.
593 
594 *Equivalence with the classical hypothesis.* If `gr R` (with its usual
595 multiplication of classes) is commutative, take `G = gr R`, `𝒜ₙ = Fₙ/Fₙ₋₁`
596 and `grₙ` the quotient maps. Conversely, the maps `grₙ` induce `k`-linear
597 isomorphisms `Fₙ/Fₙ₋₁ ≅ 𝒜ₙ` which carry the product of classes to the
598 product of `G` (`gr_mul`); since `G` is the internal direct sum of the `𝒜ₙ`,
599 their sum is a graded ring isomorphism `gr R ≅ G`. Being Noetherian and the
600 Krull dimension (`ringKrullDim`, chains of prime ideals) are invariant under
601 ring isomorphism. So the existential hypothesis below holds iff `gr R` is
602 commutative Noetherian of Krull dimension `≤ m`. The ring `G` is taken in the
603 universe of `R`, where `gr R` lives. Multiplicativity of the filtration is stated elementwise. -/

657 /-- An exhaustive increasing filtration `F₀ ⊆ F₁ ⊆ ⋯` of the `k`-algebra `R`
658 by `k`-subspaces with `1 ∈ F₀` and `Fᵢ Fⱼ ⊆ Fᵢ₊ⱼ`. -/
659 structure RingFiltration (k R : Type u) [CommRing k] [Ring R] [Algebra k R] where
660   /-- The filtration pieces `Fₙ`. -/
661   F : ℕ → Submodule k R
662   /-- `Fᵢ ⊆ Fⱼ` for `i ≤ j`. -/
663   mono : Monotone F
664   /-- `1 ∈ F₀`. -/
665   one_mem : (1 : R) ∈ F 0
666   /-- `Fᵢ Fⱼ ⊆ Fᵢ₊ⱼ`. -/
667   mul_mem : ∀ {i j : ℕ} {x y : R}, x ∈ F i → y ∈ F j → x * y ∈ F (i + j)
668   /-- The filtration is exhaustive. -/
669   exhaustive : ∀ x : R, ∃ n, x ∈ F n

671 /-- The previous filtration piece `Fₙ₋₁`, with `F₋₁ = 0`. -/
672 def RingFiltration.below {k R : Type u} [CommRing k] [Ring R] [Algebra k R]
673     (φ : RingFiltration k R) : ℕ → Submodule k R
674   | 0 => ⊥
675   | n + 1 => φ.F n

677 /-- Principal-symbol data identifying `gr R = ⨁ₙ Fₙ/Fₙ₋₁` with the commutative
678 graded algebra `G = ⨁ₙ 𝒜ₙ`: surjective `k`-linear maps `grₙ : Fₙ → 𝒜ₙ` with
679 kernel `Fₙ₋₁` that multiply symbols. -/
680 structure GradedSymbol {k R G : Type u} [CommRing k] [Ring R] [Algebra k R] [CommRing G]
681     [Algebra k G] (φ : RingFiltration k R) (𝒜 : ℕ → Submodule k G) where
682   /-- The degree-`n` symbol map `Fₙ → 𝒜ₙ`. -/
683   gr : ∀ n, φ.F n →ₗ[k] 𝒜 n
684   /-- Every homogeneous element of degree `n` is a symbol. -/
685   gr_surjective : ∀ n, Function.Surjective (gr n)
686   /-- The kernel of `grₙ` is `Fₙ₋₁`. -/
687   gr_eq_zero_iff : ∀ n (x : φ.F n), gr n x = 0 ↔ (x : R) ∈ φ.below n
688   /-- Symbols multiply: `gr_{i+j}(x y) = grᵢ(x) grⱼ(y)`. -/
689   gr_mul : ∀ i j (x : φ.F i) (y : φ.F j),
690     ((gr (i + j) ⟨x * y, φ.mul_mem x.2 y.2⟩ : 𝒜 (i + j)) : G) =
