Embedding the regular module over a simple Artinian ring

Over a simple Artinian ring A every module is a direct sum of copies of the unique simple module (Wedderburn–Artin). Hence a finitely generated module X with lengthA≤lengthX contains a copy of the regular module A, that is, an element with zero annihilator.

Main results

  • AlgebraicAnalysis.exists_injective_smul_of_length_le: if Module.length A A ≤ Module.length A X, some x:X makes a↦a⋅x injective.

References

T. Y. Lam, A First Course in Noncommutative Rings, §3 (semisimple modules and isotypic components). Nothing here is new.

Embedding the regular module. Over a simple Artinian ring A, a finitely generated module X with lengthA≤lengthX contains an element x with zero annihilator, i.e. a↦a⋅x is injective. Both modules are direct sums of copies of the unique simple module (Wedderburn–Artin), so A embeds in X.

32/-- **Embedding the regular module.** Over a simple Artinian ring `A`, a finitely
33generated module `X` with `length A ≤ length X` contains an element `x` with zero
34annihilator, i.e. `a ↦ a • x` is injective. Both modules are direct sums of copies
35of the unique simple module (Wedderburn–Artin), so `A` embeds in `X`. -/
36theorem exists_injective_smul_of_length_le {A : Type u} [Ring A] [IsSimpleRing A]
37 [IsArtinianRing A] {X : Type v} [AddCommGroup X] [Module A X] [Module.Finite A X]
38 (h : Module.length A A ≤ Module.length A X) :
39 ∃ x : X, Function.Injective fun a : A => a • x := by
40 classical
41 obtain ⟨S, hS⟩ := IsAtomic.exists_atom (Submodule A A)
42 have : IsSimpleModule A S := isSimpleModule_iff_isAtom.mpr hS
43 have hAS : IsIsotypicOfType A A S := IsSimpleRing.isIsotypic A A S
44 have hXS : IsIsotypicOfType A X S := by
45 intro T _
46 have hP := IsSimpleRing.isIsotypic A (A × X)
47 have e1 := Submodule.equivMapOfInjective (LinearMap.inl A A X) LinearMap.inl_injective S
48 have e2 := Submodule.equivMapOfInjective (LinearMap.inr A A X) LinearMap.inr_injective T
49 have : IsSimpleModule A (S.map (LinearMap.inl A A X)) := IsSimpleModule.congr e1.symm
50 have : IsSimpleModule A (T.map (LinearMap.inr A A X)) := IsSimpleModule.congr e2.symm
51 obtain ⟨e⟩ := hP (S.map (LinearMap.inl A A X)) (T.map (LinearMap.inr A A X))
52 exact ⟨e2.trans (e.trans e1.symm)⟩
53 obtain ⟨a, ⟨ea⟩⟩ := hAS.linearEquiv_fun
54 obtain ⟨b, ⟨eb⟩⟩ := hXS.linearEquiv_fun
55 have hab : a ≤ b := by
56 have h1 := ea.length_eq
57 have h2 := eb.length_eq
58 simp only [Module.length_pi, ENat.card_eq_coe_fintype_card, Fintype.card_fin,
59 Module.length_eq_one, mul_one] at h1 h2
60 rw [h1, h2] at h
61 exact_mod_cast h
62 let ι : (Fin a → S) →ₗ[A] (Fin b → S) :=
63 LinearMap.pi fun j => if hj : (j : ℕ) < a then LinearMap.proj ⟨j, hj⟩ else 0
64 have hι : Function.Injective ι := by
65 intro g g' hgg
66 funext i
67 have := congrFun hgg (Fin.castLE hab i)
68 simpa [ι, i.2] using this
69 let φ : A →ₗ[A] X := eb.symm.toLinearMap ∘ₗ ι ∘ₗ ea.toLinearMap
70 have hφ : Function.Injective φ := eb.symm.injective.comp (hι.comp ea.injective)
71 refine ⟨φ 1, fun c c' hcc => hφ ?_⟩
72 simpa [← map_smul] using hcc
73
