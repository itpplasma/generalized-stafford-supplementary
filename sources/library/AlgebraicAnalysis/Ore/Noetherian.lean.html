Right Ore conditions and right Noetherian domains

Right ideals and right modules use scalars in the opposite ring. The ascending chain argument uses the finite sums of bjaR: if aR and bR have zero intersection, cancellation makes every new summand contribute a new element.

The common-right-multiple condition is Mathlib's left Ore condition on all nonzero elements of the opposite ring. Nonempty forgets the chosen numerator and denominator functions in OreSet.

22/-- The common-right-multiple condition is Mathlib's left Ore condition on
23all nonzero elements of the opposite ring. `Nonempty` forgets the chosen
24numerator and denominator functions in `OreSet`. -/
25theorem rightOreCondition_iff_nonempty_oreSet :
26 RightOreCondition R ↔ Nonempty (OreLocalization.OreSet (Rᵐᵒᵖ)⁰) := by
27 rw [OreLocalization.nonempty_oreSet_iff_of_noZeroDivisors]
28 constructor
29 · intro h r s
30 by_cases hr : r = 0
31 · exact ⟨0, 1, by simp [hr]⟩
32 obtain ⟨x, y, hxy, hne⟩ := h (a := unop r) (b := unop s.val)
33 (by simpa using hr) (by simpa using nonZeroDivisors.coe_ne_zero s)
34 have hx : x ≠ 0 := by intro hx; simp [hx] at hne
35 exact ⟨op y, ⟨op x, mem_nonZeroDivisors_iff_ne_zero.mpr (by simpa using hx)⟩,
36 unop_injective hxy⟩
37 · intro h a b ha hb
38 obtain ⟨y, x, hxy⟩ := h (op a)
39 ⟨op b, mem_nonZeroDivisors_iff_ne_zero.mpr (by simpa using hb)⟩
40 refine ⟨unop x.val, unop y, congrArg unop hxy, mul_ne_zero ha ?_⟩
41 simpa using nonZeroDivisors.coe_ne_zero x

Finite partial sums of aR+baR+⋯, written recursively to expose cancellation of the lowest power of b.

43/-- Finite partial sums of `aR + baR + ⋯`, written recursively to expose
44cancellation of the lowest power of `b`. -/
45private def partialSum (a b : R) : ℕ → Submodule Rᵐᵒᵖ R
46 | 0 => ⊥
47 | n + 1 => principalRightIdeal a ⊔ (partialSum a b n).map (leftMulLinear b)
48
49omit [IsDomain R] in
50private theorem partialSum_mono (a b : R) : Monotone (partialSum a b) := by
51 apply monotone_nat_of_le_succ
52 intro n
53 induction n with
54 | zero => exact bot_le
55 | succ n ih => exact sup_le_sup_left (Submodule.map_mono ih) _
56
57omit [IsDomain R] in
58private theorem pow_mul_mem_partialSum (a b : R) (n : ℕ) :
59 b ^ n * a ∈ partialSum a b (n + 1) := by
60 induction n with
61 | zero => exact Submodule.mem_sup_left (by exact ⟨1, by simp [leftMulLinear]⟩)
62 | succ n ih =>
63 apply Submodule.mem_sup_right
64 exact ⟨b ^ n * a, ih, by simp [leftMulLinear, pow_succ', mul_assoc]⟩
65
66private theorem pow_mul_not_mem_partialSum (a b : R) (ha : a ≠ 0) (hb : b ≠ 0)
67 (hdis : ∀ x y : R, a * x = b * y → a * x = 0) (n : ℕ) :
68 b ^ n * a ∉ partialSum a b n := by
69 induction n with
70 | zero => simpa [partialSum] using ha
71 | succ n ih =>
72 intro hm
73 obtain ⟨u, ⟨x, rfl⟩, v, ⟨y, hy, rfl⟩, huv⟩ := Submodule.mem_sup.mp hm
74 change a * x + b * y = b ^ (n + 1) * a at huv
75 have heq : a * x = b * (b ^ n * a - y) := by
76 rw [mul_sub, ← mul_assoc, ← pow_succ']
77 exact eq_sub_of_add_eq huv
78 have hax := hdis x _ heq
79 rw [hax, zero_add, pow_succ', mul_assoc] at huv
80 exact ih ((mul_left_cancel₀ hb huv) ▸ hy)

A right Noetherian domain has nonzero common right multiples. The Noetherian hypothesis is on the right regular module, not the left one.

82/-- A right Noetherian domain has nonzero common right multiples.
83The Noetherian hypothesis is on the right regular module, not the left one. -/
84theorem rightOreCondition_of_isNoetherian [IsNoetherian Rᵐᵒᵖ R] :
85 RightOreCondition R := by
86 intro a b ha hb
87 by_contra h
88 have hdis : ∀ x y : R, a * x = b * y → a * x = 0 := by
89 intro x y hxy
90 by_contra hne
91 exact h ⟨x, y, hxy, hne⟩
92 obtain ⟨n, hn⟩ := monotone_stabilizes_iff_noetherian.mpr
93 (inferInstance : IsNoetherian Rᵐᵒᵖ R)
94 ⟨partialSum a b, partialSum_mono a b⟩
95 have heq : partialSum a b n = partialSum a b (n + 1) := hn (n + 1) (Nat.le_succ n)
96 apply pow_mul_not_mem_partialSum a b ha hb hdis n
97 rw [heq]
98 exact pow_mul_mem_partialSum a b n

Over a right Ore domain, torsion elements form a right submodule.

149/-- Over a right Ore domain, torsion elements form a right submodule. -/
150def torsionSubmodule [IsDomain R] (hOre : OreRightIntersection.RightOreCondition R) :
151 Submodule Rᵐᵒᵖ M where
152 carrier := {m | ∃ s : R, s ≠ 0 ∧ op s • m = 0}
153 zero_mem' := ⟨1, one_ne_zero, smul_zero _⟩
154 add_mem' := by
155 rintro m n ⟨a, ha, hma⟩ ⟨b, hb, hnb⟩
156 obtain ⟨x, y, hxy, hne⟩ := hOre ha hb
157 refine ⟨a * x, hne, ?_⟩
158 rw [smul_add]
159 have hm : op (a * x) • m = 0 := by
160 rw [op_mul, mul_smul, hma, smul_zero]
161 have hn : op (a * x) • n = 0 := by
162 rw [hxy, op_mul, mul_smul, hnb, smul_zero]
163 rw [hm, hn, add_zero]
164 smul_mem' := by
165 rintro r m ⟨a, ha, hma⟩
166 by_cases hr : unop r = 0
167 · refine ⟨1, one_ne_zero, ?_⟩
168 have : r = 0 := unop_injective hr
169 simp [this]
170 obtain ⟨x, y, hxy, hne⟩ := hOre hr ha
171 have hx : x ≠ 0 := by intro hx; simp [hx] at hne
172 refine ⟨x, hx, ?_⟩
173 rw [← mul_smul]
174 change op (unop r * x) • m = 0
175 rw [hxy, op_mul, mul_smul, hma, smul_zero]
