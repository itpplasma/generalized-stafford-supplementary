Ascending ring filtrations

This file defines the generic ascending filtration of a (possibly noncommutative) ring A over a commutative base ring R, and develops the foundational closure, associated-graded, order, and finiteness API that the rest of a filtered-ring / D-module layer sits on.

The pinned Mathlib has two filtration-shaped structures which do not cover this notion: Ideal.Filtration (Mathlib.RingTheory.Filtration) is a decreasing I-adic filtration of a module over a fixed ideal I, and IsRingFiltration/IsFiltration (Mathlib.RingTheory.FilteredAlgebra.Basic) are SetLike-generic classes that do not require a multiplicative unit in degree 0 or exhaustiveness, and are stated for an arbitrary Preorder index rather than for the specific N-indexed, submodule-multiplication shape used here. Neither is reused as the primary structure; both are noted so a later contributor does not duplicate the search. What is reused is Mathlib's submodule-multiplication semiring structure on Submodule R A (Mathlib.Algebra.Algebra.Operations, available for [CommSemiring R] [Semiring A] [Algebra R A]) and the quotient-bilinear-form lifting lemma LinearMap.liftQ₂ (Mathlib.LinearAlgebra.Quotient.Bilinear), which is exactly the well-definedness tool the associated-graded multiplication needs.

Main definitions

  • RingFiltration R A: an ascending, exhaustive, unital, submultiplicative family F : ℕ → Submodule R A.
  • RingFiltration.GradedQuotient φ i: the graded piece Fi/F(i−1) (with the convention F(−1)=⊥), together with RingFiltration.gradedMul, the well-defined multiplication Gradedi→Gradedj→Graded(i+j) induced on representatives.
  • RingFiltration.order: for a=0, the least filtration degree containing a.
  • RingFiltration.Separated: no oscillation — once two consecutive filtration pieces coincide, the filtration stays constant from there on.
  • RingFiltration.IsGoodFiltration: each piece is a finite R-module; the hypothesis a later Hilbert-function argument needs. Proved closed under sup and product of pieces.

No Weyl algebra, differential operator, or other application-specific structure appears in this file.

An ascending filtration of a ring A by R-submodules: monotone, containing 1 in degree 0, submultiplicative (Fi∗Fj≤F(i+j), using the submodule-multiplication semiring structure on Submodule R A), and exhaustive (⨆i,Fi=⊤).

53/-- An ascending filtration of a ring `A` by `R`-submodules: monotone,
54containing `1` in degree `0`, submultiplicative (`F i * F j ≤ F (i + j)`,
55using the submodule-multiplication semiring structure on `Submodule R A`),
56and exhaustive (`⨆ i, F i = ⊤`). -/
57structure RingFiltration (R A : Type*) [CommRing R] [Ring A] [Algebra R A] where

The filtration pieces.

58 /-- The filtration pieces. -/
59 F : ℕ → Submodule R A
60

The pieces are increasing.

60 /-- The pieces are increasing. -/
61 mono : Monotone F
62

The unit lies in degree 0.

62 /-- The unit lies in degree `0`. -/
63 one_mem : (1 : A) ∈ F 0

Submultiplicativity: Fi∗Fj⊆F(i+j).

64 /-- Submultiplicativity: `F i * F j ⊆ F (i + j)`. -/

The filtration exhausts the ring.

66 /-- The filtration exhausts the ring. -/

A product of elements of filtration degree i and j has filtration degree at most i+j.

75/-- A product of elements of filtration degree `i` and `j` has filtration
76degree at most `i + j`. -/
77theorem mul_mem_add {a b : A} {i j : ℕ} (ha : a ∈ φ.F i) (hb : b ∈ φ.F j) :
78 a * b ∈ φ.F (i + j) :=
79 φ.mul_le i j (Submodule.mul_mem_mul ha hb)
80
81

A power an of an element of filtration degree d has filtration degree at most d∗n.

81/-- A power `a ^ n` of an element of filtration degree `d` has filtration
82degree at most `d * n`. -/
83theorem pow_mem {a : A} {d : ℕ} (ha : a ∈ φ.F d) (n : ℕ) : a ^ n ∈ φ.F (d * n) := by
84 induction n with
85 | zero => simpa using φ.one_mem
86 | succ n ih =>
87 have hstep : a ^ n * a ∈ φ.F (d * n + d) := φ.mul_mem_add ih ha
88 simpa [pow_succ, Nat.mul_succ] using hstep

belowi∗Fj≤below(i+j): multiplying a below-degree-i element by a degree-j element lands below degree i+j.

113/-- `below i * F j ≤ below (i + j)`: multiplying a below-degree-`i` element
114by a degree-`j` element lands below degree `i + j`. -/
115theorem below_mul_le (i j : ℕ) : φ.below i * φ.F j ≤ φ.below (i + j) := by
116 cases i with
117 | zero => simp
118 | succ n =>
119 have heq : n + 1 + j = n + j + 1 := by omega
120 rw [below_succ, heq, below_succ]
121 exact φ.mul_le n j

Fi∗belowj≤below(i+j): multiplying a degree-i element by a below-degree-j element lands below degree i+j.

123/-- `F i * below j ≤ below (i + j)`: multiplying a degree-`i` element by a
124below-degree-`j` element lands below degree `i + j`. -/
125theorem mul_below_le (i j : ℕ) : φ.F i * φ.below j ≤ φ.below (i + j) := by
126 cases j with
127 | zero => simp
128 | succ n =>
129 have heq : i + (n + 1) = i + n + 1 := by omega
130 rw [below_succ, heq, below_succ]
131 exact φ.mul_le i n

Multiplication of representatives, landing directly in the graded quotient of the sum degree. This is not yet shown to be well defined on the graded pieces; see gradedMul for the induced, well-defined product.

133/-- Multiplication of representatives, landing directly in the graded
134quotient of the sum degree. This is *not yet* shown to be well defined on
135the graded pieces; see `gradedMul` for the induced, well-defined product. -/
136def repMul (i j : ℕ) : φ.F i →ₗ[R] φ.F j →ₗ[R] φ.GradedQuotient (i + j) :=
137 LinearMap.mk₂' R R
138 (fun a b => Submodule.Quotient.mk
139 ⟨(a : A) * (b : A), φ.mul_mem_add a.2 b.2⟩)
140 (fun a₁ a₂ b => by
141 rw [← Submodule.Quotient.mk_add]
142 congr 1
143 exact Subtype.ext (by simp [add_mul]))
144 (fun c a b => by
145 rw [← Submodule.Quotient.mk_smul]
146 congr 1
147 exact Subtype.ext (by simp))
148 (fun a b₁ b₂ => by
149 rw [← Submodule.Quotient.mk_add]
150 congr 1
151 exact Subtype.ext (by simp [mul_add]))
152 (fun c a b => by
153 rw [← Submodule.Quotient.mk_smul]
154 congr 1
155 exact Subtype.ext (by simp))

157theorem repMul_apply (i j : ℕ) (a : φ.F i) (b : φ.F j) :
158 φ.repMul i j a b =
159 Submodule.Quotient.mk (p := φ.belowInF (i + j))
160 ⟨(a : A) * (b : A), φ.mul_mem_add a.2 b.2⟩ :=
161 rfl

Changing the first representative by a below-degree-i element does not change repMul.

163/-- Changing the first representative by a below-degree-`i` element does not
164change `repMul`. -/
165theorem belowInF_le_repMul_ker (i j : ℕ) :
166 φ.belowInF i ≤ (φ.repMul i j).ker := by
167 intro x hx
168 have hx' : (x : A) ∈ φ.below i := φ.mem_belowInF.1 hx
169 refine LinearMap.mem_ker.mpr (LinearMap.ext fun y => ?_)
170 show Submodule.Quotient.mk (p := φ.belowInF (i + j)) _ = (0 : φ.GradedQuotient (i + j))
171 rw [Submodule.Quotient.mk_eq_zero]
172 exact φ.mem_belowInF.2 (φ.below_mul_le i j (Submodule.mul_mem_mul hx' y.2))

Changing the second representative by a below-degree-j element does not change repMul.

174/-- Changing the second representative by a below-degree-`j` element does not
175change `repMul`. -/
176theorem belowInF_le_repMul_flip_ker (i j : ℕ) :
177 φ.belowInF j ≤ (φ.repMul i j).flip.ker := by
178 intro y hy
179 have hy' : (y : A) ∈ φ.below j := φ.mem_belowInF.1 hy

181 show Submodule.Quotient.mk (p := φ.belowInF (i + j)) _ = (0 : φ.GradedQuotient (i + j))
182 rw [Submodule.Quotient.mk_eq_zero]
183 exact φ.mem_belowInF.2 (φ.mul_below_le i j (Submodule.mul_mem_mul x.2 hy'))

The well-defined multiplication Gradedi→Gradedj→Graded(i+j) on the associated graded module, induced from repMul on representatives. This is where the submultiplicativity hypothesis mul_le is genuinely used to show a well-defined map, not merely assumed.

185/-- The well-defined multiplication `Graded i → Graded j → Graded (i + j)` on
186the associated graded module, induced from `repMul` on representatives. This
187is where the submultiplicativity hypothesis `mul_le` is genuinely used to
188show a *well-defined* map, not merely assumed. -/
189def gradedMul (i j : ℕ) :
190 φ.GradedQuotient i →ₗ[R] φ.GradedQuotient j →ₗ[R] φ.GradedQuotient (i + j) :=
191 LinearMap.liftQ₂ (φ.belowInF i) (φ.belowInF j) (φ.repMul i j)
192 (φ.belowInF_le_repMul_ker i j) (φ.belowInF_le_repMul_flip_ker i j)
193
194@[simp] theorem gradedMul_mk (i j : ℕ) (a : φ.F i) (b : φ.F j) :
195 φ.gradedMul i j (Submodule.Quotient.mk a) (Submodule.Quotient.mk b) =
196 Submodule.Quotient.mk (p := φ.belowInF (i + j))
197 ⟨(a : A) * (b : A), φ.mul_mem_add a.2 b.2⟩ :=
198 rfl

The order of a nonzero element a: the least filtration degree containing it. Well defined by exhaustiveness of the filtration.

209/-- The order of a nonzero element `a`: the least filtration degree

211noncomputable def order {a : A} (_ha : a ≠ 0) : ℕ :=

217theorem order_le {a : A} (ha : a ≠ 0) {i : ℕ} (hi : a ∈ φ.F i) : φ.order ha ≤ i :=

The order of a product is at most the sum of the orders.

220/-- The order of a product is at most the sum of the orders. -/
221theorem order_mul_le {a b : A} (ha : a ≠ 0) (hb : b ≠ 0) (hab : a * b ≠ 0) :
222 φ.order hab ≤ φ.order ha + φ.order hb :=
223 φ.order_le hab (φ.mul_mem_add (φ.mem_order ha) (φ.mem_order hb))

The order of a sum is at most the maximum of the orders.

225/-- The order of a sum is at most the maximum of the orders. -/
226theorem order_add_le {a b : A} (ha : a ≠ 0) (hb : b ≠ 0) (hab : a + b ≠ 0) :
227 φ.order hab ≤ max (φ.order ha) (φ.order hb) := by
228 refine φ.order_le hab (add_mem ?_ ?_)
229 · exact φ.mono (le_max_left _ _) (φ.mem_order ha)
230 · exact φ.mono (le_max_right _ _) (φ.mem_order hb)

Separated filtrations and the finiteness hypothesis

232/-! ## Separated filtrations and the finiteness hypothesis -/

234

A filtration is separated when it does not oscillate: once two consecutive pieces coincide, the filtration stays constant from there on (equivalently, F is strictly increasing until it stabilises).

234/-- A filtration is separated when it does not oscillate: once two
235consecutive pieces coincide, the filtration stays constant from there on
236(equivalently, `F` is strictly increasing until it stabilises). -/
237def Separated (φ : RingFiltration R A) : Prop :=
238 ∀ i, φ.F i = φ.F (i + 1) → ∀ j, i ≤ j → φ.F j = φ.F i

A good filtration: each piece is a finite R-module. This is exactly the finite-dimensionality hypothesis a later Hilbert-function / Bernstein-type argument needs; it is not derivable from the ascending-exhaustive-unital- submultiplicative axioms alone (e.g. A itself may fail to be Noetherian over R), so it is recorded as an explicit class.
