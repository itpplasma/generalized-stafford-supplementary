Surjective symbol presentations

A RingFiltration.SymbolPresentation φ 𝒜 is a commutative graded algebra G=⨁An together with R-linear maps σn​:An​→Fn​/Fn−1​ which are surjective and multiplicative: σi+j​(gh)=σi​(g)σj​(h) in the associated graded module of A. Unlike GradedSymbol, the σn​ need not be injective. So grA is a quotient of the commutative graded algebra G, not isomorphic to it. This is the situation of a graded quotient of a symmetric algebra, such as S(g)↠grU(g), where the enveloping algebra has no PBW theorem available.

GradedSymbol.toPresentation shows that an isomorphism-type symbol is a presentation, so the results here contain those of SymbolNoetherian.

Main results

The argument is that of SymbolNoetherian, with one change. For an additive subgroup T≤A, grPieceTn is the set of homogeneous g∈An​ with σn​(g)=[u] for some u∈T∩Fn​. Surjectivity of σn​ makes every class of Fn​/Fn−1​ realised by some g, which is all that the equality step needs. Commutativity of G and multiplicativity of σ give that grT is an ideal for one-sided ideals T. Hence I↦grI is strictly monotone.

  • SymbolPresentation.isNoetherian_right, isNoetherianRing: if G is Noetherian then A is right and left Noetherian [McConnell–Robson 1.6.9].
  • SymbolPresentation.devLE_right, devLE_left: if moreover ringKrullDim G ≤ m, the ideal lattices of A have deviation at most m [MR 6.5.6, 6.4.8].
  • SymbolPresentation.devLEOmega_right, devLEOmega_left: finite Krull dimension of G gives deviation at most omega.

7# Surjective symbol presentations
8
9A `RingFiltration.SymbolPresentation φ 𝒜` is a commutative graded algebra
10`G = ⨁ 𝒜 n` together with `R`-linear maps `σₙ : 𝒜ₙ → Fₙ/Fₙ₋₁` which are
11surjective and multiplicative: `σ_{i+j}(g h) = σᵢ(g) σⱼ(h)` in the associated
12graded module of `A`. Unlike `GradedSymbol`, the `σₙ` need not be injective.
13So `gr A` is a quotient of the commutative graded algebra `G`, not isomorphic
14to it. This is the situation of a graded quotient of a symmetric algebra,
15such as `S(𝔤) ↠ gr U(𝔤)`, where the enveloping algebra has no PBW theorem
16available.
17
18`GradedSymbol.toPresentation` shows that an isomorphism-type symbol is a
19presentation, so the results here contain those of `SymbolNoetherian`.

21## Main results
22
23The argument is that of `SymbolNoetherian`, with one change. For an additive
24subgroup `T ≤ A`, `grPiece T n` is the set of homogeneous `g ∈ 𝒜ₙ` with
25`σₙ(g) = [u]` for some `u ∈ T ∩ Fₙ`. Surjectivity of `σₙ` makes every class
26of `Fₙ/Fₙ₋₁` realised by some `g`, which is all that the equality step needs.
27Commutativity of `G` and multiplicativity of `σ` give that `gr T` is an ideal
28for one-sided ideals `T`. Hence `I ↦ gr I` is strictly monotone.

64 carrier := {g | ∃ hg : g ∈ 𝒜 n, ∃ u ∈ T, ∃ hu : u ∈ φ.F n,

67 rintro a b ⟨ha, u, hu, hu', he⟩ ⟨hb, v, hv, hv', hf⟩
68 refine ⟨Submodule.add_mem _ ha hb, u + v, T.add_mem hu hv, Submodule.add_mem _ hu' hv', ?_⟩
69 rw [show (⟨a + b, Submodule.add_mem _ ha hb⟩ : 𝒜 n) = ⟨a, ha⟩ + ⟨b, hb⟩ from rfl, map_add,

73 rw [show (⟨0, Submodule.zero_mem _⟩ : 𝒜 n) = 0 from rfl, map_zero]

Equal symbols force equality. If T≤T′ and every symbol of T′ is a symbol of T, then T=T′. Surjectivity of the presentation realises each class of Fn​/Fn−1​ by a homogeneous element; exhaustiveness and F(−1)=0 finish the induction.

134/-- **Equal symbols force equality.** If `T ≤ T'` and every symbol of `T'` is a
135symbol of `T`, then `T = T'`. Surjectivity of the presentation realises each
136class of `Fₙ/Fₙ₋₁` by a homogeneous element; exhaustiveness and `F (-1) = 0`
137finish the induction. -/
138theorem eq_of_le_of_grSpan_le {T T' : AddSubgroup A} (hle : T ≤ T')
139 (hgr : P.grSpan T' ≤ P.grSpan T) : T = T' := by
140 have key : ∀ (n : ℕ) (u : A), u ∈ T' → u ∈ φ.F n →
141 ∃ v ∈ T, v ∈ φ.F n ∧ u - v ∈ φ.below n := by
142 intro n u hu hn
143 obtain ⟨⟨g, hg'⟩, hg⟩ := P.sym_surjective n (Submodule.Quotient.mk ⟨u, hn⟩)
144 have hmem : g ∈ P.grPiece T' n := ⟨hg', u, hu, hn, hg⟩
145 obtain ⟨_, v, hv, hvn, hgv⟩ :=
146 P.mem_grPiece_of_mem_grSpan (hgr (P.mem_grSpan_of_mem hg' hmem)) hg'
147 refine ⟨v, hv, hvn, ?_⟩
148 have := (Submodule.Quotient.eq (φ.belowInF n)).mp (hg.symm.trans hgv)
149 exact φ.mem_belowInF.mp this
150 refine le_antisymm hle fun u hu => ?_
151 obtain ⟨n, hn⟩ := φ.exists_mem_of_directed u
152 induction n generalizing u with
153 | zero =>
154 obtain ⟨v, hv, _, hd⟩ := key 0 u hu hn
155 rw [below_zero, Submodule.mem_bot, sub_eq_zero] at hd
156 rw [hd]
157 exact hv
158 | succ n ih =>
159 obtain ⟨v, hv, _, hd⟩ := key (n + 1) u hu hn
160 rw [below_succ] at hd
161 have := ih (u - v) (T'.sub_mem hu (hle hv)) hd
162 simpa using T.add_mem this hv

If homogeneous multiples of degree-wise symbols of T are again such symbols, then grT is closed under multiplication by G.

170/-- If homogeneous multiples of degree-wise symbols of `T` are again such
171symbols, then `gr T` is closed under multiplication by `G`. -/
172theorem mul_mem_grSpan {T : AddSubgroup A}
173 (hT : ∀ i m (r g : G), r ∈ 𝒜 i → g ∈ P.grPiece T m → r * g ∈ P.grPiece T (i + m))
174 (r : G) {g : G} (hg : g ∈ P.grSpan T) : r * g ∈ P.grSpan T := by
175 classical
176 intro n
177 rw [show r * g = ∑ i ∈ (decompose 𝒜 r).support, (decompose 𝒜 r i : G) * g by
178 rw [← Finset.sum_mul, sum_support_decompose]]
179 rw [decompose_sum, DFinsupp.finsetSum_apply, Submodule.coe_sum]
