Principal symbols with values in a commutative graded algebra

For a ring filtration φ : RingFiltration R A of a (possibly noncommutative) R-algebra A, a RingFiltration.GradedSymbol φ 𝒜 identifies the associated graded ring grA=⨁Fn/F(n−1) with a commutative N-graded R-algebra G=⨁An. It consists of R-linear maps grn:Fn→An which are surjective, have kernel F(n−1) (with F(−1)=0), and are multiplicative. These conditions say precisely that each grn induces Fn/F(n−1)≃An (RingFiltration.GradedSymbol.gradedQuotientEquiv) and that these isomorphisms carry the graded multiplication of grA to that of G. Hypotheses such as "grA is a commutative Noetherian ring" are stated through such an identification, as in [McConnell–Robson, Noncommutative Noetherian Rings, 1.6.9 and 6.5.6]; the ring structure of grA itself is never constructed.

The interface adapts the FilteredAlgebraData symbol interface of itpplasma/generalized−stafford−formal (archived GeneralizedStafford/Setting.lean) to the shared RingFiltration structure.

Main definitions

  • RingFiltration.GradedSymbol φ 𝒜: the symbol data.
  • RingFiltration.GradedSymbol.grAt n u: the degree-n symbol of u, extended by zero outside Fn.
  • RingFiltration.ofGradedAlgebra 𝒜 and RingFiltration.GradedSymbol.ofGradedAlgebra 𝒜: a graded ring filtered by degree, with associated graded ring itself.

102/-- Two elements of `F n` have the same degree-`n` symbol iff their

The degree filtration of a graded algebra: Fn consists of the elements whose homogeneous components above degree n vanish.

131/-- The degree filtration of a graded algebra: `F n` consists of the elements
132whose homogeneous components above degree `n` vanish. -/
133def degreeLE (n : ℕ) : Submodule R G where
134 carrier := {g | ∀ i, n < i → decompose 𝒜 g i = 0}
135 add_mem' := by
136 intro a b ha hb i hi
137 rw [decompose_add, add_apply, ha i hi, hb i hi, add_zero]
138 zero_mem' := by
139 intro i _
140 rw [decompose_zero, zero_apply]
141 smul_mem' := by
142 intro c a ha i hi
143 rw [decompose_smul, smul_apply, ha i hi, smul_zero]
144

146
147theorem mem_degreeLE {n : ℕ} {g : G} :
148 g ∈ degreeLE 𝒜 n ↔ ∀ i, n < i → decompose 𝒜 g i = 0 := Iff.rfl

150theorem mem_degreeLE_of_mem {n : ℕ} {g : G} (hg : g ∈ 𝒜 n) : g ∈ degreeLE 𝒜 n :=
151 fun _ hi => Subtype.ext (decompose_of_mem_ne 𝒜 hg hi.ne)

153/-- The product formula for homogeneous components of a product. -/
154theorem coe_decompose_mul_eq_sum (x y : G) (k : ℕ) :
155 (decompose 𝒜 (x * y) k : G) =
156 ∑ ij ∈ Finset.antidiagonal k, (decompose 𝒜 x ij.1 : G) * decompose 𝒜 y ij.2 := by

The degree filtration is submultiplicative.

159/-- The degree filtration is submultiplicative. -/
160theorem degreeLE_mul_le (i j : ℕ) :
161 degreeLE 𝒜 i * degreeLE 𝒜 j ≤ degreeLE 𝒜 (i + j) := by
162 rw [Submodule.mul_le]
163 intro x hx y hy k hk
164 apply Subtype.ext
165 rw [coe_decompose_mul_eq_sum, ZeroMemClass.coe_zero]
166 refine Finset.sum_eq_zero fun ab hab => ?_
167 rw [Finset.mem_antidiagonal] at hab
168 rcases lt_or_ge i ab.1 with h | h
169 · rw [hx _ h, ZeroMemClass.coe_zero, zero_mul]
170 · rw [hy _ (by omega), ZeroMemClass.coe_zero, mul_zero]

The degree filtration of a graded algebra.

173/-- The degree filtration of a graded algebra. -/
174def ofGradedAlgebra : RingFiltration R G where
175 F := degreeLE 𝒜
176 mono := fun _ _ hab _ hx i hi => hx i (lt_of_le_of_lt hab hi)
177 one_mem := mem_degreeLE_of_mem SetLike.GradedOne.one_mem
178 mul_le := degreeLE_mul_le
179 exhaustive := by
180 classical
181 refine eq_top_iff.mpr fun g _ => ?_
182 let n := (decompose 𝒜 g).support.sup id
183 refine Submodule.mem_iSup_of_mem n fun i hi => ?_
184 by_contra hne
185 have : i ∈ (decompose 𝒜 g).support := DFinsupp.mem_support_iff.mpr hne
186 exact absurd (Finset.le_sup (f := id) this) (not_le.mpr hi)

The symbol of the degree filtration of a graded algebra is the top homogeneous component; its associated graded ring is the algebra itself.

191/-- The symbol of the degree filtration of a graded algebra is the top
192homogeneous component; its associated graded ring is the algebra itself. -/
193def GradedSymbol.ofGradedAlgebra : GradedSymbol (ofGradedAlgebra 𝒜) 𝒜 where
194 gr n :=
195 { toFun := fun x => decompose 𝒜 (x : G) n
196 map_add' := fun x y => by
197 change decompose 𝒜 ((x : G) + y) n = _
198 rw [decompose_add]
199 rfl
200 map_smul' := fun c x => by
201 change decompose 𝒜 (c • (x : G)) n = _
202 rw [decompose_smul]
203 rfl }
204 gr_surjective n := fun g =>
205 ⟨⟨g, mem_degreeLE_of_mem g.2⟩, Subtype.ext (decompose_of_mem_same 𝒜 g.2)⟩
206 gr_eq_zero_iff n x := by
207 obtain ⟨x, hx⟩ := x
208 simp only [LinearMap.coe_mk, AddHom.coe_mk]
209 cases n with
210 | zero =>
211 rw [below_zero, Submodule.mem_bot]
212 constructor
213 · intro h0
214 apply (decompose 𝒜).injective
215 ext i : 1
216 rw [decompose_zero, zero_apply]
217 rcases Nat.eq_zero_or_pos i with rfl | hi
218 · exact h0
219 · exact hx i hi
220 · rintro rfl
221 rw [decompose_zero, zero_apply]
222 | succ n =>
223 rw [below_succ]
224 constructor
225 · intro h0 i hi
226 rcases Nat.lt_or_ge (n + 1) i with h | h
227 · exact hx i h
228 · obtain rfl : i = n + 1 := by omega
229 exact h0
230 · intro h
231 exact h (n + 1) (Nat.lt_succ_self n)
232 gr_mul i j x y := by
233 obtain ⟨x, hx⟩ := x
234 obtain ⟨y, hy⟩ := y
235 simp only [LinearMap.coe_mk, AddHom.coe_mk]
236 rw [coe_decompose_mul_eq_sum, Finset.sum_eq_single (i, j)]
237 · rintro ⟨a, b⟩ hab hne
238 rw [Finset.mem_antidiagonal] at hab
239 rcases lt_or_ge i a with h | h
240 · rw [hx _ h, ZeroMemClass.coe_zero, zero_mul]
241 · have hb : j < b := by
242 by_contra hb
243 exact hne (Prod.ext (by dsimp only; omega) (by dsimp only; omega))
244 rw [hy _ hb, ZeroMemClass.coe_zero, mul_zero]
245 · intro h
246 exact absurd (Finset.mem_antidiagonal.mpr (rfl : i + j = i + j)) h
