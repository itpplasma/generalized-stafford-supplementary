Simplicity of the Weyl algebras in characteristic zero

The pair stage B[x][∂;d/dx] of a simple k-algebra B is simple when k has characteristic zero. The argument is the classical one for the Weyl algebra. Let I be a nonzero two-sided ideal.

  • Commutation with the coordinate x lowers the ∂-degree by one, with leading coefficient a nonzero integer multiple, so I meets the coordinate stage B[x].
  • Commutation with ∂ lowers the x-degree by one in the same way, so I meets the base B.
  • I∩B is a nonzero two-sided ideal of B, hence contains 1.

Induction over the tower IteratedPairStage k n and transport along the presentation equivalence give IsSimpleRing (WeylAlg k n).

Provenance: this file is new in AlgebraicAnalysis. The tower and presentation it applies are the copied Weyl development of this package.

40/-- A nonzero natural number is not a left zero divisor in a `k`-algebra over a
41field of characteristic zero. -/
42theorem eq_zero_of_natCast_mul (k : Type*) [Field k] [CharZero k] {A : Type*} [Ring A]
43 [Algebra k A] {m : ℕ} (hm : m ≠ 0) {a : A}
44 (h : (m : A) * a = 0) : a = 0 := by
45 have hc : (m : k) ≠ 0 := Nat.cast_ne_zero.mpr hm
46 calc a = algebraMap k A ((m : k)⁻¹) * ((m : A) * a) := by
47 rw [← mul_assoc, ← map_natCast (algebraMap k A) m, ← map_mul,
48 inv_mul_cancel₀ hc, map_one, one_mul]

195/-- **Coordinate descent.** A nonzero two-sided ideal of the pair stage meets the

197`x` lowers the momentum degree of a normal form, with a nonzero integer

199theorem exists_coordinate_mem (k : Type*) [Field k] [CharZero k] [Algebra k B]
200 (I : Ideal (PairStage (B := B))) (hI : I.IsTwoSided) (hne : I ≠ ⊥) :

202 normalCoefficient (outerD (B := B)) s ∈ I := by
203 have key : ∀ d : ℕ, ∀ p : Polynomial (CoordinateStage (B := B)), p ≠ 0 →

206 normalCoefficient (outerD (B := B)) s ∈ I := by

217 rw [← normalForm_C, ← eq_C_of_natDegree_le_zero hdeg]
218 rw [← hC]
