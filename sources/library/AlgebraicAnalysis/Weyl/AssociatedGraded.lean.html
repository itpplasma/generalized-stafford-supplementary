Associated graded pieces of the PBW filtrations

The strict lower piece in degree N is the kernel of degree-N principal component projection. Restricting that projection to the filtered piece is surjective onto the weighted-homogeneous symbol submodule, so each filtered quotient is canonically linearly equivalent to its symbol component. The external graded multiplication is a downstream construction.

The part of a filtration piece strictly below degree N; degree zero has zero lower piece.

32/-- The part of a filtration piece strictly below degree `N`; degree zero has
33zero lower piece. -/
34def presentedStrictLowerPiece {n : ℕ} (w : PhaseVar n → ℕ) :
35 (N : ℕ) → Submodule k (PresentedWeyl k n)
36 | 0 => ⊥
37 | N + 1 => presentedWeightPiece k w N

39theorem presentedStrictLowerPiece_le {n N : ℕ}
40 (w : PhaseVar n → ℕ) :
41 presentedStrictLowerPiece k w N ≤ presentedWeightPiece k w N := by
42 cases N with
43 | zero => exact bot_le
44 | succ N => exact presentedWeightPiece_mono k w (Nat.le_succ N)

46theorem presentedPrincipalComponent_eq_zero_iff_mem_strictLower
47 {n N : ℕ} (w : PhaseVar n → ℕ) (z : PresentedWeyl k n)
48 (hz : z ∈ presentedWeightPiece k w N) :
49 presentedPrincipalComponent k w N z = 0 ↔
50 z ∈ presentedStrictLowerPiece k w N := by
51 constructor
52 · intro hp
53 cases N with
54 | zero =>
55 rw [presentedStrictLowerPiece, Submodule.mem_bot]
56 apply (presentedNormalFormLinearEquiv k n).injective
57 ext m
58 change AddMonoidAlgebra.coeff
59 ((presentedNormalFormLinearEquiv k n) z) m =
60 AddMonoidAlgebra.coeff ((presentedNormalFormLinearEquiv k n) 0) m
61 have hle := (mem_presentedWeightPiece k w 0 z).mp hz
62 change ∀ m, AddMonoidAlgebra.coeff
63 ((presentedNormalFormLinearEquiv k n) z) m ≠ 0 → monomialWeight w m ≤ 0 at hle
64 have hpc := congrArg (fun f : SymbolRing k n => AddMonoidAlgebra.coeff f m) hp
65 change AddMonoidAlgebra.coeff (presentedPrincipalComponent k w 0 z) m = 0 at hpc
66 rw [coeff_presentedPrincipalComponent] at hpc
67 by_cases hc :
68 AddMonoidAlgebra.coeff (presentedNormalFormLinearEquiv k n z) m = 0
69 · rw [hc]
70 simp
71 · have hw : monomialWeight w m = 0 := Nat.eq_zero_of_le_zero (hle m hc)
72 simpa [hw] using hpc
73 | succ N =>
74 rw [presentedStrictLowerPiece, mem_presentedWeightPiece]
75 intro m hm
76 change AddMonoidAlgebra.coeff (presentedNormalFormLinearEquiv k n z) m ≠ 0 at hm
77 have hle := (mem_presentedWeightPiece k w (N + 1) z).mp hz m hm
78 have hpc := congrArg (fun f : SymbolRing k n => AddMonoidAlgebra.coeff f m) hp
79 change AddMonoidAlgebra.coeff (presentedPrincipalComponent k w (N + 1) z) m = 0 at hpc
80 rw [coeff_presentedPrincipalComponent] at hpc
81 by_contra hnot
82 have heq : monomialWeight w m = N + 1 := by omega
83 simp [heq, hm] at hpc
84 · intro hlower
85 cases N with
86 | zero =>
87 rw [presentedStrictLowerPiece, Submodule.mem_bot] at hlower
88 subst z
89 exact map_zero _
90 | succ N =>
91 exact presentedPrincipalComponent_eq_zero_of_mem_of_lt k w z
92 hlower (Nat.lt_succ_self N)

94/-- The principal component restricted to the degree-`N` filtration piece,
95with codomain narrowed to the degree-`N` homogeneous symbol submodule. -/
96def principalComponentOnPiece {n : ℕ} (w : PhaseVar n → ℕ) (N : ℕ) :
97 presentedWeightPiece k w N →ₗ[k]
98 MvPolynomial.weightedHomogeneousSubmodule k w N where
99 toFun z := ⟨presentedPrincipalComponent k w N z,
100 MvPolynomial.weightedHomogeneousComponent_mem w
101 (presentedNormalFormLinearEquiv k n z) N⟩
102 map_add' x y := by
103 ext
104 simp [presentedPrincipalComponent]
105 map_smul' c x := by
106 ext
107 simp [presentedPrincipalComponent]

109theorem mem_ker_principalComponentOnPiece_iff {n N : ℕ}
110 (w : PhaseVar n → ℕ) (z : presentedWeightPiece k w N) :
111 z ∈ LinearMap.ker (principalComponentOnPiece k w N) ↔
112 (z : PresentedWeyl k n) ∈ presentedStrictLowerPiece k w N := by
113 rw [LinearMap.mem_ker]
114 constructor
115 · intro h
116 have hp : presentedPrincipalComponent k w N z = 0 :=
117 congrArg (fun f : MvPolynomial.weightedHomogeneousSubmodule k w N =>
118 (f : SymbolRing k n)) h
119 exact (presentedPrincipalComponent_eq_zero_iff_mem_strictLower
120 k w z z.property).mp hp
121 · intro hlower
122 apply Subtype.ext
123 exact (presentedPrincipalComponent_eq_zero_iff_mem_strictLower
124 k w z z.property).mpr hlower

The kernel of principal-component projection is exactly the strict lower filtration piece, viewed inside the degree-N piece.

126/-- The kernel of principal-component projection is exactly the strict lower
127filtration piece, viewed inside the degree-`N` piece. -/
128theorem ker_principalComponentOnPiece_eq {n N : ℕ}
129 (w : PhaseVar n → ℕ) :
130 LinearMap.ker (principalComponentOnPiece k w N) =
131 (presentedStrictLowerPiece k w N).comap
132 (presentedWeightPiece k w N).subtype := by
133 ext z
134 exact mem_ker_principalComponentOnPiece_iff k w z

136theorem principalComponentOnPiece_surjective {n N : ℕ}
137 (w : PhaseVar n → ℕ) :
138 Function.Surjective (principalComponentOnPiece k w N) := by
139 intro f
140 let z : PresentedWeyl k n :=
141 (presentedNormalFormLinearEquiv k n).symm (f : SymbolRing k n)
142 have hz : z ∈ presentedWeightPiece k w N := by
143 rw [mem_presentedWeightPiece]
144 intro m hm
145 have hnormal : presentedNormalFormLinearEquiv k n z = (f : SymbolRing k n) := by
146 exact (presentedNormalFormLinearEquiv k n).apply_symm_apply f
147 rw [hnormal] at hm
148 have hw := f.property hm
149 rw [finsupp_weight_eq_monomialWeight] at hw
150 exact le_of_eq hw
151 refine ⟨⟨z, hz⟩, ?_⟩
152 apply Subtype.ext
153 change presentedPrincipalComponent k w N z = (f : SymbolRing k n)
154 rw [presentedPrincipalComponent, LinearMap.comp_apply]
155 change MvPolynomial.weightedHomogeneousComponent w N
156 (presentedNormalFormLinearEquiv k n z) = (f : SymbolRing k n)
157 rw [show presentedNormalFormLinearEquiv k n z = (f : SymbolRing k n) from
158 (presentedNormalFormLinearEquiv k n).apply_symm_apply f]
159 exact f.property.weightedHomogeneousComponent_same

The degree-N associated graded piece, presented canonically as the quotient by the kernel of principal-component projection. The preceding kernel theorem identifies this kernel with the strict lower filtration.

170/-- The degree-`N` associated graded piece, presented canonically as the
171quotient by the kernel of principal-component projection. The preceding
172kernel theorem identifies this kernel with the strict lower filtration. -/
173abbrev presentedAssociatedGradedPiece {n : ℕ}
174 (w : PhaseVar n → ℕ) (N : ℕ) :=
175 (presentedWeightPiece k w N) ⧸
176 LinearMap.ker (principalComponentOnPiece k w N)
