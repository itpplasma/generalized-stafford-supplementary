The central-coordinate Ore stage

The zero-derivation Ore product is ordinary polynomial multiplication. This identifies the first stage in the recursive Weyl construction with a central polynomial extension and transports ordinary differentiation to it.

The zero derivation on a ring.

26/-- The zero derivation on a ring. -/
27def zeroDerivation : OreDivisionDerivation B where
28 toFun := 0
29 map_zero' := rfl
30 map_add' := by simp
31 leibniz' := by simp

33@[simp] theorem zeroDerivation_apply (b : B) : zeroDerivation b = 0 := rfl

35@[simp] theorem zeroDerivation_iterate_succ (n : ℕ) (b : B) :
36 ((zeroDerivation : B → B)^[n + 1]) b = 0 := by
37 rw [Function.iterate_succ_apply']
38 rfl

40theorem rightTerm_zeroDerivation (i : ℕ) (a b : B) (j : ℕ) :
41 rightTerm zeroDerivation i a b j = monomial (i + j) (a * b) := by
42 rw [rightTerm, Finset.sum_eq_single 0]
43 · simp
44 · intro k hk hk0
45 have hkpos : 0 < k := Nat.pos_of_ne_zero hk0
46 obtain ⟨l, rfl⟩ := Nat.exists_eq_add_of_le hkpos
47 have hzero : ((zeroDerivation : B → B)^[1 + l]) b = 0 := by
48 rw [Nat.add_comm]
49 exact zeroDerivation_iterate_succ l b
50 rw [hzero, nsmul_zero, mul_zero, monomial_zero_right]
51 · simp
52
53theorem rightMulMonomial_zeroDerivation (p : Polynomial B) (b : B) (j : ℕ) :
54 rightMulMonomial zeroDerivation p b j = p * monomial j b := by
55 induction p using Polynomial.induction_on' with
56 | add p q hp hq =>
57 rw [rightMulMonomial_add_left, hp, hq, add_mul]
58 | monomial i a =>
59 rw [rightMulMonomial,
60 Polynomial.sum_monomial_index a _ (rightTerm_zero zeroDerivation i b j)]
61 rw [rightTerm_zeroDerivation, monomial_mul_monomial]

With zero derivation, the Ore normal-form product is the ordinary central polynomial product, even for a noncommutative coefficient ring.

63/-- With zero derivation, the Ore normal-form product is the ordinary central
64polynomial product, even for a noncommutative coefficient ring. -/
65theorem rightMul_zeroDerivation_eq_mul (p q : Polynomial B) :
66 rightMul zeroDerivation p q = p * q := by
67 induction q using Polynomial.induction_on' with
68 | add q r hq hr =>
69 rw [rightMul_add, hq, hr, mul_add]
70 | monomial j b =>
71 rw [rightMul_monomial, rightMulMonomial_zeroDerivation]

Ordinary polynomial differentiation, transported to the central Ore stage.

87/-- Ordinary polynomial differentiation, transported to the central Ore
88stage. -/
89def coordinateDerivation : OreDivisionDerivation (CoordinateStage (B := B)) where
90 toFun z := normalForm zeroDerivation
91 (Polynomial.derivative ((normalFormAddEquiv zeroDerivation).symm z))
92 map_zero' := by
93 change normalForm zeroDerivation
94 (Polynomial.derivative ((normalFormAddEquiv zeroDerivation).symm 0)) = 0
95 rw [(normalFormAddEquiv zeroDerivation).symm.map_zero,
96 Polynomial.derivative_zero, normalForm_zero]
97 map_add' z w := by
98 have h := (normalFormAddEquiv zeroDerivation).symm.toAddHom.map_add z w
99 change (normalFormAddEquiv zeroDerivation).symm (z + w) =
100 (normalFormAddEquiv zeroDerivation).symm z +
101 (normalFormAddEquiv zeroDerivation).symm w at h
102 change normalForm zeroDerivation
103 (Polynomial.derivative ((normalFormAddEquiv zeroDerivation).symm (z + w))) =
104 normalForm zeroDerivation
105 (Polynomial.derivative ((normalFormAddEquiv zeroDerivation).symm z)) +
106 normalForm zeroDerivation
107 (Polynomial.derivative ((normalFormAddEquiv zeroDerivation).symm w))
108 rw [h, Polynomial.derivative_add, normalForm_add]
109 leibniz' := by
110 intro z w
111 rcases normalForm_surjective zeroDerivation z with ⟨p, rfl⟩
112 rcases normalForm_surjective zeroDerivation w with ⟨q, rfl⟩
113 rw [← normalForm_mul_zeroDerivation]
114 change normalForm zeroDerivation
115 (Polynomial.derivative ((normalFormAddEquiv zeroDerivation).symm
116 (normalForm zeroDerivation (p * q)))) =
117 normalForm zeroDerivation p *
118 normalForm zeroDerivation
119 (Polynomial.derivative ((normalFormAddEquiv zeroDerivation).symm
120 (normalForm zeroDerivation q))) +
121 normalForm zeroDerivation
122 (Polynomial.derivative ((normalFormAddEquiv zeroDerivation).symm
123 (normalForm zeroDerivation p))) *
124 normalForm zeroDerivation q
125 rw [normalFormAddEquiv_symm_normalForm,
126 normalFormAddEquiv_symm_normalForm, normalFormAddEquiv_symm_normalForm]
127 rw [Polynomial.derivative_mul, normalForm_add,
128 normalForm_mul_zeroDerivation, normalForm_mul_zeroDerivation]
129 exact add_comm _ _

132 coordinateDerivation (normalForm zeroDerivation p) =
